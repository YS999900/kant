# 1. Dictionary

Dictionary는 **Key와 Value를 한 쌍으로 저장**하는 자료구조다.

```python
user_info = {
    "name": "BaeYuSeong",
    "age": 30
}
```

## 특징

| 특징 | 설명 |
|---|---|
| `{key: value}` | Key와 Value 형태 |
| Key 중복 불가 | 같은 Key를 다시 쓰면 마지막 값으로 덮어씀 |
| Value 중복 가능 | 여러 Key가 같은 값을 가질 수 있음 |
| 입력 순서 유지 | Python 3.7+에서 삽입 순서를 보장 |
| Key로 조회 | List처럼 숫자 Index가 기본이 아님 |

---

## 값 조회 / 수정 / 추가

```python
user_info = {
    "name": "BaeYuSeong",
    "age": 30
}

print(user_info["age"])

user_info["age"] = 32
user_info["role"] = "Tutor"

print(user_info)
```

```text
user_info["age"]
→ 기존 값 조회

user_info["age"] = 32
→ 기존 값 수정

user_info["role"] = "Tutor"
→ 새로운 Key와 Value 추가
```

# 3. Dictionary 주요 메서드

```python
menu = {
    "coffee": 4000,
    "tea": 4500
}
```

| 메서드 | 기능 |
|---|---|
| `keys()` | Key 목록 형태의 View |
| `values()` | Value 목록 형태의 View |
| `items()` | `(Key, Value)` 쌍 |
| `get(key)` | Key의 Value 조회 |
| `get(key, 기본값)` | Key가 없으면 기본값 반환 |

예:

```python
print(menu.keys())
print(menu.values())
print(menu.items())
```

`items()`는 반복문에서 많이 사용한다.

```python
for name, price in menu.items():
    print(name, price)
```

# 4. Dictionary와 in

Dictionary에 `in`을 사용하면 기본적으로 **Key가 존재하는지 확인**한다.

```python
menu = {
    "coffee": 4000,
    "tea": 4500
}

print("coffee" in menu)         # True
print(4000 in menu)             # False
print(4000 in menu.values())    # True
```

즉:

```text
값 in dictionary
→ Key 검사

값 in dictionary.values()
→ Value 검사
```

# 5. get()

다음 코드는 Key가 없으면 오류가 발생한다.

```python
menu["cake"]
```

반면 `get()`은 안전하게 조회할 수 있다.

```python
price = menu.get("cake", 5000)

print(price)
```

결과:

```text
5000
```

기본값을 지정하지 않으면:

```python
print(menu.get("cake"))
```

결과:

```text
None
```

# 6. Set

Set은 **중복을 허용하지 않는 집합 자료형**이다.

```python
grade = {1, 2, 3}
```

또는:

```python
grade = set([1, 2, 2, 3, 3])
```

결과:

```text
{1, 2, 3}
```

## 특징

| 특징 | 설명 |
|---|---|
| 중복 없음 | 같은 값은 한 번만 저장 |
| 순서에 의존하면 안 됨 | Index로 접근하지 않음 |
| 집합 연산 가능 | 교집합, 합집합, 차집합 |

---

# 9. Set 연산

```python
set_a = {1, 2, 3}
set_b = {3, 4, 5}
```

| 연산 | 코드 | 결과 |
|---|---|---|
| 교집합 | `set_a & set_b` | `{3}` |
| 합집합 | `set_a \| set_b` | `{1,2,3,4,5}` |
| 차집합 | `set_a - set_b` | `{1,2}` |
| 포함 여부 | `3 in set_a` | `True` |

# 10. Set으로 중복 제거

```python
raw_emails = [
    "a@sparta.com",
    "b@sparta.com",
    "a@sparta.com"
]

unique_emails = list(set(raw_emails))
```

중복은 제거되지만 **원래 순서를 기대하면 안 된다.**

순서까지 유지하려면:

```python
unique_emails = list(dict.fromkeys(raw_emails))

print(unique_emails)
```

결과:

```text
['a@sparta.com', 'b@sparta.com']
```

정렬까지 하고 싶다면:

```python
print(sorted(set(["c", "d", "a", "f", "a"])))
```

결과:

```text
['a', 'c', 'd', 'f']
```

# 11. if 조건문

기본 구조:

```python

    실행할 코드
elif 다른_조건식:
    실행할 코드
```

```python

    print("에어컨을 끕니다.")
```

# 12. 들여쓰기

Python에서는 들여쓰기가 문법이다.

```python
if temp >= 28:
    print("에어컨을 켭니다.")
    print("1시간 후 종료")
```

일반적으로 **공백 4칸**을 사용한다.

```text
if 조건:
    같은 블록
    같은 블록
```

같은 블록에서 들여쓰기가 제멋대로 달라지면 오류가 날 수 있다.

# 13. Truthy / Falsy

Python은 Boolean이 아니어도 조건식으로 판단할 수 있다.

```python

    print("결제를 진행합니다.")
else:
    print("장바구니가 비었습니다.")
```

대표적인 Falsy 값:

```text
False
None
0
0.0
""
[]
{}
set()
```

비어 있지 않은 List 등은 보통 True로 판단된다.

# 16. if 조건 순서

조건은 **위에서 아래로 검사**한다.

잘못된 예:

```python
score = 95

if score >= 80:
    print("B")
elif score >= 90:
    print("A")
```

결과:

```text
B
```

이미 첫 번째 조건이 True이기 때문에 아래 `elif`를 확인하지 않는다.

따라서 범위가 큰 조건부터:

```python
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
```

처럼 작성한다.

# 21. while

조건이 True인 동안 반복한다.

```python
num = 1

while num < 3:
    print(f"현재 숫자는 {num}")
    num += 1
```

결과:

```text
현재 숫자는 1
현재 숫자는 2
```

## 주의

조건을 언젠가 False로 만들지 않으면 무한 반복할 수 있다.

```python
count = 3

while count > 0:
    print(count)
    count -= 1
```

# 22. break와 continue

## break

반복문을 즉시 종료한다.

```python
for num in range(1, 6):
    if num == 3:
        break

    print(num)
```

결과:

```text
1
2
```

## continue

현재 반복만 건너뛰고 다음 반복으로 이동한다.

```python
for num in range(1, 6):
    if num % 2 == 0:
        continue

    print(f"홀수 {num}")
```

결과:

```text
홀수 1
홀수 3
홀수 5
```

# 24. 중첩 반복문

반복문 안에 반복문을 사용할 수 있다.

```python
for x in range(2, 10):
    print(f"--- {x}단 ---")

    for y in range(1, 10):
        print(f"{x} x {y} = {x * y}")
```

## break 주의

`break`는 **현재 자신이 들어 있는 가장 가까운 반복문 하나만 종료**한다.

```python
for x in range(2, 10):
    for y in range(1, 10):
        if y == 6:
            break
```

이 경우 `y` 반복문만 종료되고 `x` 반복문은 계속된다.

# 25. 숫자 맞히기 게임

```python
import random

number = random.randint(1, 100)
try_count = 0

print("=" * 45)
print("컴퓨터가 1부터 100 사이의 숫자를 생성했습니다.")
print("=" * 45)

while True:
    user_input = input("숫자를 맞춰보세요 (1~100, 종료 q): ")

    if user_input == "q":
        print(f"게임을 종료합니다. 정답은 {number}입니다.")
        break

    if not user_input.isdecimal():
        print("숫자만 입력해주세요.")
        continue

    user_number = int(user_input)

    if user_number < 1 or user_number > 100:
        print("1~100 사이의 값을 입력하세요.")
        continue

    try_count += 1

    if user_number < number:
        print("Up! 더 큰 수입니다.")

    elif user_number > number:
        print("Down! 더 작은 수입니다.")

    else:
        print(f"정답입니다. {try_count}회 만에 성공했습니다.")
        break
```

## 사용한 개념

| 코드 | 의미 |
|---|---|
| `import random` | random 모듈 사용 |
| `randint(1, 100)` | 1~100 사이 정수 생성 |
| `while True` | 무한 반복 |
| `input()` | 사용자 입력 |
| `isdecimal()` | 숫자 문자 여부 확인 |
| `int()` | 문자열 → 정수 |
| `continue` | 현재 반복 건너뛰기 |
| `break` | 반복 종료 |
| `+= 1` | 값 1 증가 |

`random.randint(1, 100)`은 **1과 100을 모두 포함**한다.

# 오늘 수정할 부분

| 기존 이해 | 정확한 내용 |
|---|---|
| `del` 메서드 | `del`은 Python 문(statement) |
| Dictionary는 Index로 절대 조회 불가 | 기본적으로 Key로 조회하며 `keys()` 등을 List로 변환하면 위치 접근 가능 |
| `"coffee" in menu`인데 Key가 `coffe` | 철자를 `coffee`로 통일해야 True |
| `4000 in menu` | Dictionary에서는 Key를 검사하므로 False |
| Set은 순서가 있음 | Set은 순서에 의존하면 안 됨 |
| `remove()`와 `discard()`가 같음 | 없는 값에서 `remove()`는 오류, `discard()`는 오류 없음 |
| `if score >= 80` 후 `elif >= 90` | 넓은 조건이 먼저라 95도 B가 됨 |
| 들여쓰기 3칸/4칸 혼용 | 같은 블록은 일관되게, 일반적으로 4칸 |
| `break`가 모든 반복문 종료 | 가장 가까운 반복문 하나만 종료 |
| `try_count++` | Python에서는 `try_count += 1` |
| `&` = 엔드퍼센트 | `&` = ampersand |
