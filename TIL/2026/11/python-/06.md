- `if`를 이용한 기본값 설정
- `random.randint()`를 활용한 난수 생성

---

## 1. 주요 개념

| 문법 | 기능 |
|---|---|
| `HANDS = {1: "가위", ...}` | 번호와 가위바위보를 딕셔너리로 관리 |
| `def 함수명():` | 함수 정의 |
| `input()` | 사용자 입력받기 |
| `.strip()` | 문자열 양쪽 공백 제거 |
| `return` | 함수의 결과값 반환 |
| `random.randint(1, 3)` | 1~3 사이의 정수 무작위 선택 |
| `HANDS[number]` | 딕셔너리의 키로 값 조회 |
| `main()` | 메인 함수 호출 |

## 2. 함수별 역할

```python
# 가위바위보 데이터
HANDS = {1: "가위", 2: "바위", 3: "보"}

# 게임 제목 출력
def show_title():
    print("=" * 40)
    print("가위/바위/보 게임")
    print("=" * 40)

# 플레이어 이름 입력
def ask_name():
    name = input("플레이어 이름: ").strip()

    if name == "":
        name = "게스트"

    return name
```

함수마다 역할을 구분하면 코드의 가독성과 재사용성이 좋아진다.

## 3. main() 함수

```python
def main():
    show_title()
    name = ask_name()

    computer_number = random.randint(1, 3)

    print(f"{name}님, 컴퓨터는 {HANDS[computer_number]}를 냈습니다.")

main()
```

`main()`은 프로그램의 주요 실행 흐름을 관리하는 함수다.

```text
main() 실행
    ↓
show_title() → 게임 제목 출력
    ↓
ask_name() → 플레이어 이름 입력
    ↓
random.randint() → 컴퓨터 선택
    ↓
선택 결과 출력
```

## 4. 추가로 알아둘 부분

| 개념 | 설명 |
|---|---|
| `.strip()` | 함수가 아닌 문자열 메서드이며, 양쪽 공백만 제거 |
| `return name` | 입력받은 이름을 호출한 곳으로 반환 |
| `HANDS[computer_number]` | 숫자 키에 대응하는 가위·바위·보 조회 |
| `main()` | 정의만 하면 실행되지 않으며 직접 호출해야 함 |
