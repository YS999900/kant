## 2. Product 클래스

```python
class Product:
    next_id = 1

    def __init__(self, name, price, stock):
        self.id = Product.next_id
        Product.next_id += 1

        self.name = name
        self.price = price
        self.stock = stock

    def is_sold_out(self):
        return self.stock == 0

    def __str__(self):
        stock_text = "품절" if self.is_sold_out() else f"재고 {self.stock}개"
        return f"{self.id}: {self.name:<10} {self.price:>8,} {stock_text}"
```

### 상품 상태 확인

```python
def is_sold_out(self):
    return self.stock == 0
```

재고가 0개이면 `True`, 그렇지 않으면 `False`를 반환한다.

### 조건부 표현식

```python
stock_text = "품절" if self.is_sold_out() else f"재고 {self.stock}개"
```

| 조건 | 결과 |
|---|---|
| `True` | `"품절"` |
| `False` | `"재고 N개"` |

일반적인 `if / else`를 한 줄로 표현한 것이다.

### 문자열 출력 형식

| 문법 | 의미 |
|---|---|
| `{self.name:<10}` | 문자열을 10칸 너비로 왼쪽 정렬 |
| `{self.price:>8,}` | 숫자를 8칸 너비로 오른쪽 정렬, 천 단위 쉼표 표시 |
| `__str__()` | 객체를 출력할 때 사용할 문자열 반환 |

## 3. 파일 분리와 import

```python
from product import Product
```

`product.py`에 작성한 `Product` 클래스를 다른 파일에서 사용할 수 있다.

```text
shopping_cart/
├── product.py
```

### 직접 실행과 import의 차이

```python
if __name__ == "__main__":
    products = [
        Product("텀블러", 15_000, 10),
        Product("무선 이어폰", 80_000, 3)
    ]

    for p in products:
        print(p)
```

| 실행 방식 | 테스트 코드 실행 |
|---|---|
| `uv run product.py` | 실행됨 |

`if __name__ == "__main__":` 안에 테스트 코드를 배치하면 다른 파일에서 클래스를 불러올 때 테스트 코드가 실행되지 않는다.

## 4. Cart 클래스 — 장바구니

### 상품 추가

```python
def add(self, product, qty):
    if product.is_sold_out():
        print("품절된 상품입니다.")
        return

    in_cart_qty = self.items.get(product, 0)
    extra_qty = product.stock - in_cart_qty

    if qty > extra_qty:
        print(f"재고가 부족합니다. (담을 수 있는 수량: {extra_qty}개)")
        return

    self.items[product] = in_cart_qty + qty
    print(f"{product.name} {qty}개를 담았습니다.")
```

### 핵심 변수

| 변수 | 의미 |
|---|---|
| `product` | 장바구니에 담을 상품 객체 |
| `qty` | 추가할 수량 |
| `in_cart_qty` | 이미 장바구니에 담긴 수량 |
| `extra_qty` | 추가로 담을 수 있는 수량 |

**재고 계산 예시**

재고가 10개이고 이미 장바구니에 7개가 있다면:

```python
extra_qty = 10 - 7  # 3
```

추가로 3개까지 담을 수 있다.

### 상품 제거

```python
def remove(self, product, qty):
    if product not in self.items:
        print("장바구니에 해당 상품이 없습니다.")
        return

    if qty >= self.items[product]:
        del self.items[product]
    else:
        self.items[product] -= qty
```

| 상황 | 동작 |
|---|---|
| 상품이 없음 | 제거하지 않음 |
| 제거 수량이 담긴 수량 이상 | 상품 전체 삭제 |
| 제거 수량이 담긴 수량보다 적음 | 수량 감소 |

## 5. 장바구니 상태와 금액 계산

### 장바구니 비어 있는지 확인

```python
def is_empty(self):
    return len(self.items) == 0
```

`len()`은 딕셔너리에 저장된 항목의 개수를 반환한다.

장바구니가 비어 있으면 `True`, 상품이 있으면 `False`이다.

### 상품 합계

```python
def subtotal(self):
    return sum(p.price * q for p, q in self.items.items())
```

장바구니의 모든 상품에 대해 `가격 × 수량`을 계산하고 더한다.

| 문법 | 의미 |
|---|---|
| `p` | 상품 객체 |
| `q` | 수량 |
| `p.price * q` | 상품별 금액 |
| `.items()` | 딕셔너리의 키와 값을 함께 조회 |
| `sum()` | 각 상품 금액을 모두 더함 |

### 배송비 계산

```python
def shipping(self):
    if self.is_empty():
        return 0

    return 0 if self.subtotal() >= 30_000 else 3_000
```

장바구니가 비어 있으면 0원, 상품 합계가 30,000원 이상이면 무료배송, 그 외에는 3,000원이다.

### 최종 금액

```python
def total(self):
    return self.subtotal() + self.shipping()
```

현재 단계에서는 할인 기능이 연결되지 않았으므로 상품 합계와 배송비만 더한다.

## 6. 결제 처리 checkout()

```python
def checkout(self):
    if self.is_empty():
        return

    self.show()

    for p, q in self.items.items():
        p.stock -= q

    self.items.clear()

    print("결제가 완료되었습니다. 감사합니다!")
```

### 실행 순서

```text
checkout() 실행
    ↓
장바구니가 비어 있는지 확인
    ↓
결제 정보 출력
    ↓
상품별 재고 감소
    ↓
장바구니 초기화
    ↓
결제 완료 메시지 출력
```

**기억할 점**

`p.stock -= q`는 실제 상품 객체의 재고를 변경한다.

반면 `self.items.clear()`는 장바구니 딕셔너리를 비우는 메서드이다.

## 7. Coupon 클래스 — 상속과 super()

### 부모 클래스

```python
class Coupon:
    def __init__(self, name):
        self.name = name

    def discount_amount(self, total):
        return 0
```

부모 클래스는 모든 쿠폰이 공통으로 사용하는 이름과 할인 금액 계산 메서드를 정의한다.

### 비율 할인 쿠폰

```python
class PercentCoupon(Coupon):
    def __init__(self, rate, max_discount):
        super().__init__("비율 할인 쿠폰")
        self.rate = rate
        self.max_discount = max_discount
```

### 정액 할인 쿠폰

```python
class FixedCoupon(Coupon):
    def __init__(self, amount, min_total):
        super().__init__("정액 할인 쿠폰")
        self.amount = amount
        self.min_total = min_total
```

| 개념 | 설명 |
|---|---|
| 상속 | 부모 클래스의 공통 기능 물려받기 |
| `super().__init__()` | 부모 클래스 초기화 메서드 호출 |
| 오버라이딩 | 부모와 같은 이름의 메서드를 자식에서 재정의 |
| 다형성 | 같은 메서드 호출로 쿠폰마다 다른 할인 계산 수행 |

쿠폰의 할인 계산 메서드는 아직 구현 중이며, 이후 `discount_amount()`를 완성하고 장바구니에 연결할 예정이다.

## 8. WSL과 Ubuntu 개발 환경 구축

### WSL (Windows Subsystem for Linux)

Windows 안에서 Linux 환경을 실행할 수 있도록 지원하는 기능이다.

일반 설치 과정에서 `403` 오류가 발생하여 Windows 기능을 수동으로 활성화한 후 설치했다.

```powershell
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
```

```powershell
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
```

이후 WSL 설치 파일을 직접 설치하고 Ubuntu 배포판을 설치했다.

```powershell
wsl --install -d Ubuntu
```

### Ubuntu 기본 명령어

| 명령어 | 기능 |
|---|---|
| `wsl --version` | WSL 버전 확인 |
| `wsl --list --verbose` | 설치된 Linux 배포판 목록 확인 |
| `whoami` | 현재 사용자 확인 |
| `lsb_release -a` | Ubuntu 버전 확인 |
| `sudo apt update` | 패키지 목록 업데이트 |
| `sudo apt upgrade -y` | 설치된 패키지 업데이트 |

설치된 환경에서 Ubuntu 26.04.1 LTS와 WSL 3.0.5.0을 확인했다.

## 9. Docker 환경 구축

Docker는 애플리케이션을 실행하는 데 필요한 환경을 컨테이너로 구성하고 실행하는 플랫폼이다.

### Docker 설치 과정

Ubuntu에서 다음 명령어를 실행했으나 오류가 발생했다.

```bash
winget install Docker.DockerDesktop
```

`winget`은 Windows 패키지 관리자이므로 Ubuntu 터미널에서는 사용할 수 없다.

Docker Desktop은 Windows 환경에서 설치해야 한다.

```powershell
winget install --id Docker.DockerDesktop -e
```

### Windows와 Ubuntu의 차이

| 구분 | Windows | Ubuntu |
|---|---|---|
| 패키지 관리자 | `winget` | `apt` |
| 터미널 | PowerShell | Bash |
| 프로그램 설치 예시 | `winget install` | `sudo apt install` |
| Docker 환경 | Docker Desktop | WSL 연동으로 Docker 사용 |

### Docker 설치 후 확인할 명령어

```bash
docker --version
```

```bash
docker run hello-world
```

Docker Desktop 설치 및 Ubuntu 연동은 별도로 확인할 예정이다.
