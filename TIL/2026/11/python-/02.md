# 1. 변수와 자료형

Python의 변수는 **오른쪽의 값을 왼쪽 이름에 연결**해서 사용한다.

```python
age = 25
name = "BaeYuSeong"
```

변수는 다른 값을 다시 할당할 수도 있다.

```python
age = 20
age = 25

print(age)  # 25
```

## 기본 자료형

| 자료형 | Python | 예 |
|---|---|---|
| 정수 | `int` | `25` |
| 실수 | `float` | `3.14` |
| 문자열 | `str` | `"hello"` |
| 불리언 | `bool` | `True`, `False` |
| 리스트 | `list` | `[1, 2, 3]` |
| 튜플 | `tuple` | `(1, 2, 3)` |

자료형 확인:

```python
type(age)
```

형 변환:

```python
int("3")   # 3
str(3)     # "3"
```

# 2. 연산자

## 산술 연산자

| 연산자 | 의미 | 예 |
|---|---|---|
| `+` | 더하기 | `10 + 2` |
| `-` | 빼기 | `10 - 2` |
| `*` | 곱하기 | `10 * 2` |
| `/` | 나누기 | `10 / 2` |
| `//` | 몫 | `10 // 3` |
| `%` | 나머지 | `10 % 3` |
| `**` | 거듭제곱 | `10 ** 2` |

복합 대입:

```python
score = 100
score += 50
```

위 코드는 다음과 같다.

```python
score = score + 50
```

---

## 비교 연산자

| 연산자 | 의미 |
|---|---|
| `==` | 같다 |
| `!=` | 다르다 |
| `>` | 크다 |
| `<` | 작다 |
| `>=` | 크거나 같다 |
| `<=` | 작거나 같다 |

```python
a = 10

print(a == 10)  # True
print(a > 10)   # False
```

비교 결과는:

```text
True 또는 False
```

---

## 논리 연산자

| 연산자 | 의미 |
|---|---|
| `and` | 둘 다 True |
| `or` | 하나라도 True |
| `not` | True / False 반전 |

```python
is_adult = True
has_ticket = False

print(is_adult and has_ticket)  # False
print(is_adult or has_ticket)   # True
print(not is_adult)             # False
```

### 계산 순서

대표적으로:

```text
괄호
↓
산술 연산
↓
비교
↓
not
↓
and
↓
or
```

헷갈리면 괄호를 사용한다.

```python
result = (10 + 2) * 5 > 25
```

# 3. 문자열과 f-string

문자열 안에 값을 넣을 때 f-string을 사용할 수 있다.

```python
name = "Cake"
age = 29

print(f"{name} {age}살")
```

## 숫자 출력 형식

천 단위 쉼표:

```python
price = 15000

print(f"{price:,}원")
```

결과:

```text
15,000원
```

소수점 둘째 자리:

```python
pi = 3.141592

print(f"{pi:.2f}")
```

결과:

```text
3.14
```

정렬:

```python
print(f"{15000:>8,}")
```

| 기호 | 의미 |
|---|---|
| `<` | 왼쪽 정렬 |
| `>` | 오른쪽 정렬 |
| `^` | 가운데 정렬 |

# 4. Index와 Slicing

Python의 Index는 **0부터 시작**한다.

```python
colors = ["red", "green", "blue"]
```

```text
red     green     blue
 0        1         2

-3       -2        -1
```

```python
print(colors[0])   # red
print(colors[-1])  # blue
```

## Slicing

기본 형태:

```python
값[start:stop:step]
```

예:

```python
numbers = [0, 1, 2, 3, 4, 5]
```

| 코드 | 결과 | 의미 |
|---|---|---|
| `numbers[1:4]` | `[1,2,3]` | 1부터 4 미만 |
| `numbers[:3]` | `[0,1,2]` | 앞에서 3개 |
| `numbers[3:]` | `[3,4,5]` | 3부터 끝 |
| `numbers[::2]` | `[0,2,4]` | 2칸씩 |
| `numbers[::-1]` | 역순 | 뒤집기 |

> `stop` 위치의 값은 포함하지 않는다.

# 5. List와 Tuple

## List

```python
shopping_list = ["apple", "banana", "carrot"]
```

List는 값을 변경할 수 있다.

```python
shopping_list[0] = "kiwi"
```

```text
List = Mutable
       변경 가능
```

## Tuple

```python
axis = (338.123, 41.123)
```

Tuple은 생성 후 요소를 직접 수정할 수 없다.

```text
Tuple = Immutable
        변경 불가
```

다음처럼 괄호 없이 만들 수도 있다.

```python
point = 1, 2, 3
```

# 6. List 메서드

| 메서드 | 기능 |
|---|---|

# 8. 다차원 List와 Tuple 꺼내기

```python
orders = [
    ("Latte", 5000, 2),
    ("Americano", 3000, 1),
]
```

두 번째 주문:

```python
orders[1]
```

두 번째 주문의 첫 번째 값:

```python
orders[1][0]
```

결과:

```text
Americano
```

Tuple 값을 각각 나눠 받을 수도 있다.

```python
order = ("Latte", 5000, 2)

menu, price, qty = order
```

---

# 9. 반복문

List나 Tuple의 값을 하나씩 꺼내 반복할 수 있다.

```python
for x in xs:
    print(x)
```

Tuple을 바로 나눠 받을 수도 있다.

```python
for menu, price, qty in orders:
    subtotal = price * qty
    print(menu, subtotal)
```

# 11. GitHub CLI

GitHub CLI는 터미널에서 GitHub 기능을 사용할 수 있게 해준다.

```text
gh = GitHub CLI
```

## 로그인

| 명령어 | 기능 |
|---|---|
| `gh auth login` | GitHub 로그인 |
| `gh auth status` | 로그인 상태 / 권한 확인 |
| `gh auth refresh -s 권한` | 권한 추가 |

---

## Repository

| 명령어 | 기능 |
|---|---|
| `gh repo clone OWNER/REPO` | Repository 복제 |
| `gh repo view` | 현재 Repository 확인 |
| `gh repo list` | 내 Repository 목록 |
| `gh repo create 이름` | Repository 생성 |
| `gh repo delete OWNER/REPO` | Repository 삭제 |

Private Repository 생성:

```bash
gh repo create kant_python --private
```

---

## Issue / Pull Request

| 명령어 | 기능 |
|---|---|
| `gh issue create` | Issue 생성 |
| `gh issue list` | Issue 목록 |
| `gh pr create` | Pull Request 생성 |
| `gh pr list` | PR 목록 |
| `gh pr view` | PR 확인 |
| `gh pr merge 번호` | PR 병합 |

> Commit과 Push는 기본적으로 `git`, GitHub의 Repository / Issue / PR 기능은 `gh`를 사용한다.
