## 1. 조건문 (Conditional Statements)

조건에 따라 실행할 코드를 결정한다.

| 문법 | 기능 |
|---|---|
| `if 조건:` | 조건이 참이면 실행 |
| `elif 조건:` | 앞 조건이 거짓일 때 추가 검사 |
| `else:` | 앞선 조건이 모두 거짓일 때 실행 |
| `and` | 두 조건이 모두 참 |
| `or` | 하나 이상 참 |
| `not` | 참과 거짓 반전 |
| `not in` | 값이 포함되지 않았는지 검사 |
| `==` | 두 값이 같은지 비교 |
| `=` | 변수에 값 할당 |

### if / elif / else

```python
score = 95

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")
```

결과: `A`

> 조건문은 위에서 아래로 검사하며, 처음 참인 분기만 실행한다.

### 여러 조건과 범위 비교

```python
is_login = True
has_permission = True

if is_login and has_permission:
    print("관리자 페이지 이동")

hour = 12

if 9 <= hour < 18:
    print("영업시간입니다.")

menu = ["coffee", "latte"]

if "cake" not in menu:
    print("케이크가 없습니다.")
```

### Truthy / Falsy

```python
orders = ["coffee"]

if orders:
    print("주문이 있습니다.")
```

비어 있지 않은 리스트는 참으로 판단한다.

### 들여쓰기

```python
if True:
    print("첫 번째 실행")
    print("두 번째 실행")
```

Python은 들여쓰기로 코드 블록을 구분한다. 일반적으로 공백 4칸을 사용한다.

## 2. 반복문 (Loops)

반복문은 동일한 작업을 여러 번 실행한다.

| 문법 | 기능 |
|---|---|
| `for` | 반복 가능한 데이터를 순회 |
| `while` | 조건이 참인 동안 반복 |
| `range(n)` | 0부터 n 미만까지 |
| `range(a, b)` | a부터 b 미만까지 |
| `enumerate()` | 순번과 값을 함께 추출 |
| `break` | 가장 가까운 반복문 종료 |
| `continue` | 현재 반복을 건너뛰기 |

### for / range

```python
for i in range(1, 6):
    print(i)
```

결과: `1 2 3 4 5`

`range()`는 마지막 숫자를 포함하지 않는다.

### enumerate()

```python
fruits = ["apple", "banana", "cherry"]

for index, fruit in enumerate(fruits, 1):
    print(index, fruit)
```

결과:

```text
1 apple
2 banana
3 cherry
```

`enumerate(fruits, 1)`에서 `1`은 순번을 시작할 숫자다.

### while

```python
num = 1

while num <= 3:
    print(num)
    num += 1
```

결과: `1 2 3`

조건이 언젠가 거짓이 되도록 작성해야 의도치 않은 무한 반복을 피할 수 있다.

### break와 continue

```python
for num in range(1, 6):
    if num == 3:
        break
    print(num)
```

결과: `1 2`

```python
for num in range(1, 6):
    if num % 2 == 0:
        continue
    print(num)
```

결과: `1 3 5`

### 중첩 반복문

```python
for x in range(2, 4):
    for y in range(1, 4):
        print(f"{x} x {y} = {x * y}")
```

반복문 안에서 다른 반복문을 실행한다. 표나 구구단, 2차원 리스트 처리에 사용할 수 있다.

### 누적 계산

```python
prices = [1000, 2000, 3000]

total = 0

for price in prices:
    total += price

print(total)  # 6000
```

`total += price`는 `total = total + price`와 같은 의미다.

## 3. 함수 (Function)

함수는 **특정 작업을 하나로 묶어 재사용하는 기능**이다.

### 기본 문법

```python
def 함수이름(매개변수):
    실행할_코드
    return 결과값
```

| 용어 | 의미 |
|---|---|
| `def` | 함수 정의 |
| Parameter | 함수 정의에서 받는 변수 |
| Argument | 호출할 때 전달하는 실제 값 |
| `return` | 값 반환 및 함수 종료 |
| `print()` | 결과를 화면에 출력 |
| `snake_case` | 함수명에 권장되는 표기법 |

### 함수 정의와 호출

```python
def say_hello(name, age):
    print(f"안녕하세요. 저는 {name}입니다.")
    print(f"나이는 {age}살입니다.")

say_hello("배유성", 30)
```

### print와 return 차이

```python
def add(a, b):
    return a + b

result = add(10, 5)
print(result)  # 15
```

- `print()` : 사람이 결과를 확인할 때 사용
- `return` : 함수 결과를 다른 계산이나 변수에서 사용

## 4. 매개변수와 인수

### 기본값 (Default Parameter)

```python
def say_hello(name, age, point=1000):
    print(f"{name}: {age}세 / {point}점")

say_hello("배유성", 30)
say_hello("배유성", 30, 2000)
```

기본값이 있는 매개변수는 일반적으로 기본값 없는 매개변수 뒤에 둔다.

### 키워드 인수

```python
say_hello("배유성", age=30, point=2000)
```

키워드 인수를 사용하면 매개변수 이름으로 값을 지정한다.

### 가변 인수

| 문법 | 기능 | 자료형 |
|---|---|---|
| `*args` | 여러 위치 인수 받기 | Tuple |
| `**kwargs` | 여러 키워드 인수 받기 | Dictionary |

```python
def add_all(*numbers):
    return sum(numbers)

print(add_all(1, 2, 3))     # 6
print(add_all(1, 2, 3, 4))  # 10
```

```python
def user_info(**data):
    for key, value in data.items():
        print(f"{key}: {value}")

user_info(name="스파르타", level=5)
```

`args`와 `kwargs`는 관례적인 이름이다. 실제 문법의 핵심은 `*`, `**`이다.

## 5. return과 여러 값 반환

### 하나의 값 반환

```python
def check_sign(number):
    if number > 0:
        return "양수"
    elif number < 0:
        return "음수"
    else:
        return "0"

print(check_sign(10))   # 양수
print(check_sign(-20))  # 음수
```

### 여러 값 반환

```python
def calc_value(a, b):
    plus = a + b
    minus = a - b
    return plus, minus

result1, result2 = calc_value(10, 5)

print(result1)  # 15
print(result2)  # 5

result = calc_value(10, 5)
print(result)   # (15, 5)
```

| 표현 | 의미 |
|---|---|
| `return plus, minus` | 튜플로 두 값 반환 |
| `a, b = 함수()` | 튜플의 값을 각각 나눠 받기 |
| `result = 함수()` | 튜플 하나로 받기 |
| `return` | 함수 종료, `None` 반환 |
| `return 값` | 값을 반환하고 종료 |

### 평균 계산 함수

```python
def get_average(*scores):
    if not scores:
        return None

    return sum(scores) / len(scores)

print(get_average(80, 90, 100))  # 90.0
print(get_average())             # None
```

빈 튜플은 거짓으로 판단되므로 `if not scores:`를 사용할 수 있다.

## 6. 미니 계산기 실습

```python
def add(a, b):
    return a + b

def minus(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    if b == 0:
        return "0으로 나눌 수 없습니다."
    return a / b

try:
    a = int(input("첫 번째 숫자: "))

```

`input()`은 문자열을 반환하므로 숫자로 계산하려면 `int()` 또는 `float()` 등의 변환이 필요하다.

## 7. 변수 스코프 (Scope)

변수 스코프는 **변수를 사용할 수 있는 범위**를 의미한다.

| 구분 | 의미 |
|---|---|
| Local | 함수 내부에서 정의된 지역 변수 |
| Enclosing | 바깥 함수의 변수 |
| Global | 모듈 수준에서 정의된 전역 변수 |
| Built-in | `print`, `len` 같은 내장 이름 |

### 지역 변수와 전역 변수

```python
message = "전역 메시지"

def greeting():
    message = "지역 메시지"
    print(message)

greeting()
print(message)
```

결과:

```text
지역 메시지
전역 메시지
```

함수 안에서 같은 이름으로 값을 할당하면 별도의 지역 변수가 만들어질 수 있다.

### global 키워드

```python
counter = 0

def inc_counter():
    global counter
    counter += 1

inc_counter()
inc_counter()

print(counter)  # 2
```

`global`은 함수 안에서 전역 변수에 값을 할당하겠다고 선언한다.

### 권장 방법: return 활용

```python
def inc_counter(counter):
    return counter + 1

counter = 0
counter = inc_counter(counter)
counter = inc_counter(counter)

print(counter)  # 2
```

전역 변수를 직접 변경하기보다 인수와 `return`을 사용하는 방식이 대체로 관리하기 쉽다.

## 8. 리스트 참조와 복사

함수에 리스트를 전달하면 같은 리스트 객체를 참조할 수 있다.

### 원본 리스트가 변경되는 경우

```python
cart = ["apple"]

def add_item(items):
    items.append("banana")

add_item(cart)

print(cart)
```

결과:

```text
['apple', 'banana']
```

`append()`는 리스트 자체를 변경한다.

### 원본을 지키려면 copy()

```python
cart = ["apple"]

def add_item(items):
    new_cart = items.copy()
    new_cart.append("banana")
    return new_cart

result = add_item(cart)

print(cart)    # ['apple']
print(result)  # ['apple', 'banana']
```

> `copy()`는 얕은 복사이므로, 리스트 안에 또 다른 리스트 같은 변경 가능한 객체가 있다면 내부 객체까지 독립적으로 복사되지는 않는다.

## 9. Lambda 표현식

Lambda는 간단한 함수를 **하나의 표현식으로 작성**하는 방법이다.

```python
lambda 매개변수: 표현식
```

### 일반 함수와 비교

```python
def add_five(x):
    return x + 5

print(add_five(10))  # 15
```

```python
add_five = lambda x: x + 5

print(add_five(20))  # 25
```

짧은 함수가 필요한 곳에서 자주 사용한다. 재사용할 함수라면 `def`가 더 명확한 경우가 많다.

## 10. map()과 filter()

| 함수 | 기능 |
|---|---|
| `map()` | 각 요소에 함수를 적용 |
| `filter()` | 조건을 만족하는 요소 추출 |
| `list()` | 결과를 리스트로 변환 |

### map()

```python
numbers = [1, 2, 3, 4, 5]

result = list(map(lambda x: x + 10, numbers))

print(result)
```

결과:

```text
[11, 12, 13, 14, 15]
```

### filter()

```python
numbers = [1, 2, 3, 4, 5]

result = list(filter(lambda x: x % 2 == 0, numbers))

print(result)
```

결과:

```text
[2, 4]
```

### 리스트 컴프리헨션 비교

| 목적 | Lambda / 함수 방식 | 리스트 컴프리헨션 |
|---|---|---|
| 10 더하기 | `map(lambda x: x+10, numbers)` | `[x+10 for x in numbers]` |
| 짝수 추출 | `filter(lambda x: x%2==0, numbers)` | `[x for x in numbers if x%2==0]` |
| 제곱 계산 | `map(lambda x: x**2, numbers)` | `[x**2 for x in numbers]` |

## 11. Lambda로 정렬하기

```python
players = [
    ("손흥민", 95),
    ("김민재", 60),
    ("이강인", 80)
]
```

| 코드 | 기능 |
|---|---|
| `sorted(players, key=lambda p: p[1])` | 점수 오름차순 |
| `sorted(players, key=lambda p: p[1], reverse=True)` | 점수 내림차순 |
| `max(players, key=lambda p: p[1])` | 최고 점수 선수 반환 |

여기서:

```python
lambda p: p[1]
```

은 각 튜플의 두 번째 값인 **점수를 비교 기준으로 사용**한다는 의미다.

### 제곱 후 20 이상 추출

```python
numbers = [2, 3, 4, 5, 6, 7]

squares = list(map(lambda n: n ** 2, numbers))

result = list(filter(lambda n: n >= 20, squares))

print(squares)
print(result)
```

결과:

```text
[4, 9, 16, 25, 36, 49]
[25, 36, 49]
```

## 12. 오늘 수정한 부분

| 기존 내용 / 오해 | 올바른 내용 |
|---|---|
| `numver > 0` | `number > 0` |
| `plue = a + b` | `plus = a + b` |
| `0`도 음수로 처리 | `elif number < 0`으로 구분 |
| `result2`를 두 번 할당 | 각각 `result2`, `result3`으로 구분 |
| `3과목 평균`을 두 번 출력 | `3과목`, `5과목` 구분 |
| `input()`을 그대로 계산 | `int()` 등의 변환 필요 |
| 전역 변수는 함수 안에서 자유롭게 재할당 | 재할당 시 일반적으로 `global` 필요 |
| `map()`은 값을 단순 반환 | 모든 요소에 함수를 적용 |
| `while`에는 반드시 초기값이 있어야 함 | 반드시 필요한 것은 아니지만 종료 가능한 조건 설계가 중요 |
| `cart.copy()`는 완전한 독립 복사 | 얕은 복사이므로 중첩 객체에 주의 |
| 조건문에서 `=` 사용 | 비교는 `==`, 할당은 `=` |
