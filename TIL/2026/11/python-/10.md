## 2. 클래스 변수와 인스턴스 변수

```python
class Pet:
    count = 0

    def __init__(self, name):
        self.name = name
        self.hunger = 30
        self.happy = 70
        self.energy = 70
        self.alive = True

        Pet.count += 1


choco = Pet("초코")
dubu = Pet("두부")

print(Pet.count)   # 2
print(choco.name)  # 초코
print(dubu.name)   # 두부
```

클래스 변수는 모든 객체가 공유하고, 인스턴스 변수는 객체마다 독립적으로 관리된다.

| 구분 | 클래스 변수 | 인스턴스 변수 |
|---|---|---|
| 선언 위치 | 클래스 내부 | `self`를 통해 설정 |
| 데이터 | 객체들이 공유 | 객체마다 독립 |
| 예시 | `Pet.count` | `self.hunger` |
| 용도 | 전체 입양 수 | 개별 펫의 상태 |

## 3. 특수 메서드 `__str__()`

```python
def __str__(self):
    state = self.mood() if self.alive else "떠남"

    return (f"{self.name} {state}\n"
            f"배고픔: {self.bar(self.hunger)} {self.hunger:>3}\n"
            f"행복도: {self.bar(self.happy)} {self.happy:>3}\n"
            f"에너지: {self.bar(self.energy)} {self.energy:>3}\n")
```

`__str__()`은 객체를 `print()`로 출력할 때 표시할 문자열을 정의하는 메서드이다.

| 문법 | 설명 |
|---|---|
| `f"{self.name}"` | 객체의 이름을 문자열에 삽입 |
| `self.mood()` | 현재 펫의 기분 반환 |
| `A if 조건 else B` | 조건에 따른 값 선택 |
| `\n` | 줄바꿈 |
| `{value:>3}` | 3칸을 확보하고 오른쪽 정렬 |

### 상태 막대 구현

```python
def bar(self, value):
    filled = value // 10
    return "*" * filled + "-" * (10 - filled)
```

0~100 사이의 수치를 10칸의 막대로 표현한다.

```text
배고픔: ****------  40
행복도: ******----  60
에너지: ******----  65
```

## 4. 공통 메서드를 활용한 상태 관리

```python
def _clamp(self, value):
    if value < 0:
        return 0
    if value > 100:
        return 100
    return value


def _change(self, hunger=0, happy=0, energy=0):
    self.hunger = self._clamp(self.hunger + hunger)
    self.happy = self._clamp(self.happy + happy)
    self.energy = self._clamp(self.energy + energy)
```

`_clamp()`는 상태값이 0~100 범위를 벗어나지 않도록 제한하고, `_change()`는 여러 상태값을 한 번에 변경한다.

| 메서드 | 역할 |
|---|---|
| `_clamp()` | 값의 최솟값과 최댓값 제한 |
| `_change()` | 배고픔, 행복도, 에너지 변경 |
| `self._clamp()` | 같은 객체의 메서드 호출 |
| `_` 접두사 | 내부 사용을 나타내는 관례 |

## 5. 펫 행동 메서드

```python
def feed(self):
    if self.hunger <= 10:
        print(f"{self.name}: 배불러요~")
        return False

    self._change(hunger=-30, happy=5)
    print(f"{self.name}에게 밥을 줬습니다.")
    return True
```

펫의 상태에 따라 행동 가능 여부를 판단하고, 성공하면 상태값을 변경한다.

| 행동 | 배고픔 | 행복도 | 에너지 |
|---|---:|---:|---:|
| `feed()` | -30 | +5 | 0 |
| `play()` | +10 | +25 | -20 |
| `sleep()` | +5 | 0 | +40 |

- `feed()`: 배고픔이 10 이하이면 밥주기 불가
- `play()`: 에너지가 20 미만이면 놀기 불가
- `sleep()`: 에너지 회복
- `return True / False`: 행동 성공 여부 반환

## 6. 시간 경과와 랜덤 이벤트

```python
def pass_time(self):
    # 하루 경과
    self._change(hunger=10, happy=-10, energy=-5)

    # 20% 확률 이벤트
    if random.randint(1, 5) == 1:
        self._change(happy=15)
        print(f"{self.name} 숨겨진 장난감을 찾았어요")

    # 생존 조건
    if self.hunger >= 100 or self.happy <= 0:
        self.alive = False
```

하루가 지날 때마다 펫의 상태가 변경되고, 20% 확률로 행복도가 증가하는 이벤트가 발생한다.

| 조건 | 결과 |
|---|---|
| `hunger >= 100` | 펫이 떠남 |
| `happy <= 0` | 펫이 떠남 |
| `random.randint(1, 5) == 1` | 20% 확률로 이벤트 발생 |
| `self.alive = False` | 생존 상태 종료 |

### while 반복문

```python
day = 1

while choco.alive:
    choco.pass_time()

    print(f"{day}일차 : 배고픔 {choco.hunger}, 행복도 {choco.happy}")

    day += 1

print(choco)
```

`choco.alive`가 `True`인 동안 반복하며, `False`가 되면 반복문이 종료된다.

## 7. 오류 해결 및 추가 학습

| 문제 | 원인 및 해결 |

| `slef.happy` | `self.happy`로 오타 수정 |
| 입양 수가 `2.0`으로 출력 | `count = 0.`을 `count = 0`으로 수정 |
