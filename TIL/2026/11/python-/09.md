- 캡슐화(Encapsulation)와 `__`를 이용한 속성 관리

---

## 1. 주요 개념

| 문법 | 기능 |
|---|---|
| `class Dog(Animal):` | Animal 클래스를 상속받는 Dog 클래스 정의 |
| `def sound(self):` | 자식 클래스에서 같은 이름의 메서드를 재정의하면 오버라이딩 |
| `super().__init__()` | 부모 클래스의 초기화 메서드 호출 |
| `self.__money` | 이름 맹글링을 적용하여 외부의 직접 접근을 어렵게 함 |
| `get_money()` | 내부 데이터 조회 (Getter) |
| `set_money()` | 조건을 검사한 후 데이터 변경 (Setter) |

## 2. 상속 (Inheritance)

```python
class Animal:
    def breathe(self):
        print("숨을 쉽니다.")

    def sound(self):
        print("소리를 냅니다.")


class Dog(Animal):
    def bark(self):
        print("멍멍")


dog1 = Dog()

dog1.breathe()  # 숨을 쉽니다.
dog1.bark()     # 멍멍
```

상속은 부모 클래스의 속성과 메서드를 자식 클래스가 물려받아 사용하는 기능이다.

| 구분 | 설명 |
|---|---|
| Parent / Base / Super Class | 부모 클래스 |
| Child / Derived / Subclass | 자식 클래스 |
| `Dog(Animal)` | Animal을 상속받는 Dog 클래스 |
| `breathe()` | 부모에게 물려받은 메서드 |
| `bark()` | 자식 클래스의 고유 메서드 |

## 3. 메서드 오버라이딩 (Method Overriding)

```python
class Cat(Animal):
    def sound(self):
        print("야옹")


nabi = Cat()
nabi.sound()    # 야옹
nabi.breathe()  # 숨을 쉽니다.
```

오버라이딩은 부모 클래스에서 정의한 메서드를 자식 클래스에서 **같은 이름으로 재정의**하는 것이다.

| 구분 | 상속 | 오버라이딩 |
|---|---|---|
| 목적 | 부모 기능 재사용 | 부모 기능 재정의 |
| 예시 | `breathe()` | `sound()` |

## 4. super() 활용

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age


class Student(Person):
    def __init__(self, name, age, major):
        super().__init__(name, age)
        self.major = major


std1 = Student("손흥민", 32, "스포츠댄스")

print(std1.name)   # 손흥민
print(std1.age)    # 32
print(std1.major)  # 스포츠댄스
```

`super()`는 부모 클래스의 기능을 호출할 때 사용한다.

```text
Student() 객체 생성
    ↓
Student.__init__() 실행
    ↓
super().__init__(name, age)
    ↓
Person.__init__() 실행
    ↓
name, age 속성 설정
    ↓
major 속성 설정
```

자식 클래스에서 `__init__()`을 재정의한 경우, 부모의 초기화 기능을 사용하려면 `super().__init__()` 등을 통해 호출해야 한다.

## 5. 캡슐화 (Encapsulation)

```python
class Secret:
    def __init__(self):
        self.__password = "1234"


my_password = Secret()

print(my_password._Secret__password)
# 1234
```

캡슐화는 데이터와 관련 메서드를 하나로 묶고, 데이터에 접근하는 방식을 관리하는 개념이다.

| 문법 | 설명 |
|---|---|
| `self.name` | 일반 속성 |
| `self._name` | 내부 사용을 나타내는 관례 |
| `self.__name` | 이름 맹글링(Name Mangling) 적용 |
| `_Secret__password` | 변환된 이름으로 접근 가능 |

`__`를 사용해도 완벽하게 숨겨지는 것은 아니며, 의도하지 않은 접근과 이름 충돌을 줄이는 역할을 한다.

## 6. Getter / Setter

```python
class Wallet:
    def __init__(self):
        self.__money = 1000

    def get_money(self):
        return self.__money

    def set_money(self, amount):
        if amount >= 0:
            self.__money = amount
        else:
            print("잘못된 값입니다.")


wallet = Wallet()

wallet.set_money(2000)
print(wallet.get_money())  # 2000

wallet.set_money(-500)     # 잘못된 값입니다.
print(wallet.get_money())  # 2000
```

| 구분 | 기능 | 예시 |
|---|---|---|
| Getter | 내부 데이터 조회 | `get_money()` |
| Setter | 내부 데이터 변경 및 검증 | `set_money(2000)` |
| `return` | 조회한 값을 반환 | `return self.__money` |
| `if amount >= 0` | 유효한 값인지 검사 | 음수 입력 방지 |

Setter를 활용하면 잘못된 값이 저장되는 것을 방지할 수 있다.

## 7. 추가로 알아둘 부분

| 개념 | 설명 |
|---|---|
| `class Dog(Animal)` | 괄호 안에 상속받을 부모 클래스를 작성 |
| 오버라이딩 | 부모 메서드와 같은 이름으로 다시 정의 |
| `super()` | 메서드 탐색 순서(MRO)에 따라 부모 쪽 기능을 호출 |
| `__init__()` | 객체 생성 시 속성을 초기화하는 메서드 |
| `self.__변수명` | 완전한 비공개가 아닌 이름 맹글링 |
| Getter / Setter | 모든 속성에 필수는 아니며, 데이터 접근과 검증이 필요할 때 사용 |
