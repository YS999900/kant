## 1. 클래스와 객체

클래스는 **객체를 만들기 위한 설계도**이고, 객체는 그 설계도를 이용해 만든 실제 데이터와 기능의 묶음이다.

| 용어 | 의미 | 예시 |
|---|---|---|
| Class | 객체를 만드는 설계도 | `class User:` |
| Object | 클래스로 만든 객체 | `User("손흥민")` |
| Instance | 특정 클래스에서 생성한 객체 | `user_a`가 참조하는 객체 |
| Attribute | 객체가 가지고 있는 속성 | `self.name` |
| Method | 클래스에 정의된 함수 | `show()` |
| `self` | 현재 메서드를 사용하는 객체 자신 | `self.name` |
| `__init__()` | 인스턴스 초기화 메서드 | 이름과 가격 설정 |

### 클래스 정의 및 객체 생성

```python
class User:
    def __init__(self, name):
        self.name = name

    def show(self):
        return f"회원 이름: {self.name}"

# 객체 생성
user_a = User("손흥민")
user_b = User("이강인")

print(user_a.name)
print(user_b.name)

print(user_a.show())
print(user_b.show())
```

결과:

```text
손흥민
이강인
회원 이름: 손흥민
회원 이름: 이강인
```

### 클래스와 인스턴스 구분

```text
User 클래스 (설계도)
       │
       ├── user_a 객체
       │      └── name = "손흥민"
       │
       └── user_b 객체
              └── name = "이강인"
```

같은 클래스로 만들었지만 객체마다 서로 다른 값을 저장할 수 있다.

## 2. self와 인스턴스 변수

```python
def __init__(self, name):
    self.name = name
```

| 코드 | 의미 |
|---|---|
| `self` | 현재 객체 자신 |
| `name` | 외부에서 전달받은 매개변수 |
| `self.name` | 객체가 가지고 있는 속성 |
| `self.name = name` | 전달받은 값을 객체 속성에 저장 |

### 객체 확인

```python
print(type(user_a))
print(user_a is user_b)

print(id(user_a))
print(id(user_b))
```

- `type()` : 객체의 자료형 확인
- `is` : 두 변수가 같은 객체를 가리키는지 확인
- `id()` : 객체의 고유 식별값 확인

`user_a is user_b`는 `False`다. 서로 다른 인스턴스이기 때문이다.

## 3. 함수와 메서드 차이

| 구분 | 함수(Function) | 메서드(Method) |
|---|---|---|
| 정의 | 특정 작업을 수행하는 코드 | 클래스 안에 정의되어 사용되는 함수 |
| 예시 | `print()` | `user_a.show()` |
| 호출 | `함수명()` | `객체.메서드명()` |
| `self` | 일반 함수에는 필요 없음 | 일반적인 인스턴스 메서드에서 사용 |

### 사용 예시

```python
# 일반 함수
def hello():
    print("안녕하세요")

hello()

# 메서드
user_a.show()
```

메서드 호출 시 Python이 해당 인스턴스를 `self`에 자동으로 전달한다.

## 4. 생성자와 인스턴스 속성

`__init__()`은 인스턴스가 만들어질 때 자동으로 호출되는 초기화 메서드다.

### Monitor 클래스

```python
class Monitor:
    def __init__(self):
        self.resolution = "1920x1080"
        self.size = "27인치"

    def display_info(self):
        print(f"해상도: {self.resolution}")
        print(f"크기: {self.size}")

monitor = Monitor()
monitor.display_info()
```

원래 작성한 코드에서는 `display_info()` 안에서 속성을 만들었지만, 초기 설정값은 `__init__()`에 넣는 것이 더 적절하다.

### SmartPhone 클래스

```python
class SmartPhone:
    def __init__(self, model):
        self.model = model
        self.battery = 50

    def charge(self, amount):
        if amount <= 0:
            print("충전량은 0보다 커야 합니다.")
            return

        self.battery = min(100, self.battery + amount)
        print(f"현재 배터리: {self.battery}%")

phone_a = SmartPhone("아이폰")
phone_b = SmartPhone("갤럭시")

phone_a.charge(30)
phone_b.charge(18)
```

`phone_a`와 `phone_b`는 서로 다른 인스턴스이므로 배터리 상태도 별도로 관리된다.

`min(100, 값)`을 사용하면 배터리가 100%를 초과하지 않도록 제한할 수 있다.

## 5. 특수 메서드 __str__()와 __repr__()

Python에는 `__init__()`처럼 양쪽에 언더스코어 두 개가 붙는 특수 메서드가 있다.

| 메서드 | 주요 역할 |
|---|---|
| `__init__()` | 인스턴스 초기화 |
| `__str__()` | 사람이 읽기 쉬운 문자열 표현 |
| `__repr__()` | 개발자가 객체를 확인하기 위한 표현 |

### __str__() 예시

```python
class User:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        return f"사용자: {self.name}"

user = User("손흥민")

print(user)
```

결과:

```text
사용자: 손흥민
```

`print(user)`를 호출하면 객체의 `__str__()` 결과를 사용한다.

## 6. BankAccount 클래스

예금주와 잔액을 관리하며 입금과 출금을 처리하는 클래스다.

### 주요 메서드

| 메서드 | 역할 |
|---|---|
| `__init__()` | 예금주와 초기 잔액 설정 |
| `__str__()` | 계좌 정보 문자열 반환 |
| `deposit()` | 입금 처리 |
| `withdraw()` | 출금 처리 및 잔액 확인 |

### 전체 코드

```python
class BankAccount:
    def __init__(self, owner, balance):
        self.owner = owner
        self.balance = balance

    def __str__(self):
        return f"예금주: {self.owner}, 잔액: {self.balance:,}원"

    # 입금
    def deposit(self, amount):
        if amount <= 0:
            print("올바른 입금액을 입력하세요.")
            return self.balance

        self.balance += amount
        print(f"{amount:,}원 입금 완료")
        return self.balance

    # 출금
    def withdraw(self, amount):
        if amount <= 0:
            print("올바른 출금액을 입력하세요.")
            return self.balance

        if self.balance < amount:
            print("잔액이 부족합니다.")
            return self.balance

        self.balance -= amount
        print(f"{amount:,}원 출금 완료")
        return self.balance


account_a = BankAccount("배유성", 100_000)

print(account_a)

account_a.deposit(500_000)

account_a.withdraw(1_000_000)

print(f"잔액: {account_a.withdraw(200_000):,}원")
print(f"잔액: {account_a.withdraw(300_000):,}원")
```

### 잔액 변화

| 작업 | 금액 | 잔액 |
|---|---:|---:|
| 최초 | - | 100,000원 |
| 입금 | +500,000원 | 600,000원 |
| 출금 실패 | -1,000,000원 시도 | 600,000원 |
| 출금 | -200,000원 | 400,000원 |
| 출금 | -300,000원 | 100,000원 |

### 수정한 부분

기존 코드에서는 `__str__()`이 두 번 정의되어 있었다. 같은 이름으로 다시 정의하면 나중에 작성한 메서드가 앞선 메서드를 대체한다.

또한 출금에 실패했을 때 `return 0`을 사용하면 실제 잔액이 0원인 것처럼 오해할 수 있다.

이번 예제에서는 **출금 실패 시에도 변경되지 않은 현재 잔액을 반환**하도록 수정했다.

> 실제 금융 서비스라면 금액 자료형 검사, 음수 초기 잔액 방지, 거래 기록, 동시성 처리 등이 추가로 필요하다.

## 7. ShoppingCart 클래스

상품 객체를 리스트에 저장하고 추가·삭제·조회하는 클래스다.

### 역할 구분

| 클래스 | 역할 | 속성 |
|---|---|---|
| `Item` | 상품 정보 저장 | `name`, `price` |
| `ShoppingCart` | 상품 목록 관리 | `bucket` |

### Item 클래스

```python
class Item:
    def __init__(self, name, price):
        self.name = name
        self.price = price
```

### ShoppingCart 클래스

```python
class ShoppingCart:
    def __init__(self):
        self.bucket = []

    # 상품 추가
    def add_item(self, item):
        self.bucket.append(item)

    # 상품 삭제
    def remove_item(self, item):
        if item in self.bucket:
            self.bucket.remove(item)
        else:
            print("장바구니에 없는 상품입니다.")

    # 상품 목록 반환
    def show_items(self):
        return self.bucket.copy()
```

### 상품 생성 및 장바구니 사용

```python
# 상품 3개 생성
item_a = Item("초코파이", 5000)
item_b = Item("새우깡", 2000)
item_c = Item("빅파이", 3000)

# 장바구니 생성
cart = ShoppingCart()

# 상품 추가
cart.add_item(item_a)
cart.add_item(item_b)
cart.add_item(item_c)

# 상품 삭제
cart.remove_item(item_b)

# 상품 목록 조회
for item in cart.show_items():
    print(item.name, item.price)
```

실행 결과:

```text
초코파이 5000
빅파이 3000
```

## 8. ShoppingCart 주요 코드 해석

| 코드 | 의미 |
|---|---|
| `self.bucket = []` | 객체의 상품 목록 초기화 |
| `cart = ShoppingCart()` | 장바구니 인스턴스 생성 |
| `cart.add_item(item_a)` | 상품 추가 메서드 호출 |
| `self.bucket.append(item)` | 상품 객체를 리스트에 추가 |
| `self.bucket.remove(item)` | 상품 객체를 리스트에서 삭제 |
| `return self.bucket.copy()` | 상품 목록 리스트를 얕게 복사해서 반환 |
| `for item in cart.show_items()` | 반환된 목록을 순회 |
| `item.name` | 상품 이름 접근 |
| `item.price` | 상품 가격 접근 |

### 쇼핑카트 구조

```text
ShoppingCart 클래스
       ↓
cart 객체
       │
       └── bucket 리스트
             │
             ├── item_a (초코파이)
             ├── item_b (새우깡)
             └── item_c (빅파이)
```

`remove_item(item_b)` 실행 후 `bucket`에는 `item_a`, `item_c`만 남는다.

## 9. 추가로 알아두면 좋은 내용

### ① 리스트는 변경 가능한 객체

```python
items = ["사과"]
other = items

other.append("바나나")

print(items)
```

결과:

```text
['사과', '바나나']
```

`other`와 `items`가 같은 리스트를 참조하기 때문이다.

### ② copy()와 원본 리스트

```python
items = ["사과"]
other = items.copy()

other.append("바나나")

print(items)  # ['사과']
print(other)  # ['사과', '바나나']
```

`copy()`는 새로운 리스트를 만들지만, 내부에 중첩된 변경 가능한 객체가 있다면 그 객체까지 복제하지는 않는다.

### ③ remove() 사용 시 주의

```python
items = ["사과"]

items.remove("바나나")
```

존재하지 않는 값을 삭제하면 `ValueError`가 발생한다.

따라서:

```python
if "바나나" in items:
    items.remove("바나나")
```

처럼 확인하면 좋다.

### ④ 객체 리스트 출력과 __repr__()

```python
print([account_a, account_c])
```

이런 리스트 출력에서는 객체의 `__repr__()`이 사용된다.

`__repr__()`을 따로 정의하지 않았다면 객체의 기본 표현이 출력될 수 있다.

사람이 읽기 쉽게 출력하려면:

```python
for account in [account_a, account_c]:
    print(account)
```

처럼 반복하면서 `__str__()` 결과를 출력할 수 있다.

## 10. 오늘 잘못 작성한 부분

| 기존 내용 | 문제 | 수정 |
|---|---|---|
| `__str__()` 두 번 정의 | 나중 정의가 앞 정의를 대체 | 한 번만 정의 |
| `return 0` | 출금 실패 시 잔액으로 오해 가능 | 현재 잔액 반환 |
| 출금 전 양수 검사 없음 | 음수 출금 시 잔액 증가 가능 | `amount <= 0` 검사 |
| 입금 전 양수 검사 없음 | 음수 입금 가능 | 양수 검사 추가 |
| `self`는 클래스 자체 | 실제로는 해당 인스턴스 참조 | 객체 자신으로 이해 |
| `__init__()`은 클래스 생성 시 실행 | 인스턴스 생성 시 초기화에 사용 | 의미 수정 |
| `remove()` 바로 실행 | 없는 상품이면 오류 발생 | `if item in ...` 확인 |
| `show_items()`와 `show_item()` 혼용 | 메서드 이름 불일치 | `show_items()`로 통일 |
| 리스트 반환 시 원본 노출 | 외부에서 리스트를 변경할 수 있음 | 필요 시 `copy()` 반환 |
| 메서드 = 일반 함수와 완전히 같음 | 객체와 연결되어 사용되는 함수 | 함수와 메서드 구분 |

## 오늘의 한 줄 정리

> 클래스를 이용해 데이터와 기능을 하나의 객체로 묶고, `self`와 인스턴스 속성을 활용하여 각 객체의 상태를 독립적으로 관리하는 방법을 학습했다. 은행 계좌와 쇼핑카트 실습으로 메서드 호출, 객체 참조, 리스트 관리 방법을 익혔다.
