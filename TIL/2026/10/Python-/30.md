# 1. uv란?

`uv`는 Python 프로젝트에서 다음 작업들을 관리할 수 있는 도구다.

```text
Python 버전 관리
가상환경 관리
패키지 설치/삭제
의존성 관리
Python 프로그램 실행
```

---

## uv 설치

Windows 터미널에서 설치 가능한 패키지 확인:

```bash
winget search uv
```

설치:

```bash
winget install uv
```

버전 확인:

```bash
uv --version
```

> `winget install uv`는 Python 자체가 아니라 `uv`를 설치하는 명령어다.

---

# 2. Python 프로젝트 생성

## 기본 프로젝트 생성

```bash
uv init --no-package
```

현재 폴더를 Python 프로젝트로 초기화한다.

프로젝트 설정 파일 등이 생성된다.

예:

```text
.git/
.gitignore
.python-version
README.md
main.py
pyproject.toml
```

설치된 파일 확인:

```bash
ls -al
```

---

## 특정 Python 버전으로 프로젝트 생성

```bash
uv init --no-package --python 3.13
```

Python `3.13`을 사용하는 프로젝트로 초기화한다.

---

# 3. Python 버전 확인 및 변경

## 프로젝트 Python 버전 확인

```bash
cat .python-version
```

예:

```text
3.13
```

`.python-version`은 프로젝트에서 사용하도록 지정한 Python 버전을 나타낸다.

---

## Python 버전 지정

```bash
uv python pin 3.12
```

프로젝트에서 사용할 Python 버전을 `3.12`로 지정한다.

다만 `pyproject.toml`에:

```toml
requires-python = ">=3.13"
```

이라고 되어 있는데:

```bash
uv python pin 3.12
```

를 실행하면 버전 조건이 맞지 않아 오류가 발생할 수 있다.

이 경우 프로젝트가 Python 3.12도 지원하도록:

```toml
requires-python = ">=3.12"
```

처럼 수정해야 한다.

# 5. Python 프로그램 실행

프로젝트의 Python 환경에서 실행:

```bash
uv run main.py
```

`main.py`를 프로젝트 환경에서 실행한다.

필요한 경우 uv가 `.venv` 생성이나 환경 동기화 작업도 처리할 수 있다.

즉:

```text
uv run main.py
```

는 단순히:

```text
가상환경 생성
```

이 아니라:

```text
프로젝트의 Python 환경을 사용해서 main.py 실행
```

이라고 이해하는 것이 정확하다.

# 6. 가상환경

가상환경은 **프로젝트마다 Python과 패키지를 독립적으로 관리하기 위한 환경**이다.

예:

```text
Project A
└─ FastAPI 0.x

Project B
└─ FastAPI 1.x
```

서로 다른 프로젝트에서 필요한 패키지 버전이 달라도 충돌하지 않게 관리할 수 있다.

uv 프로젝트에서는 보통:

```text
.venv/
```

폴더에 가상환경이 만들어진다.

---

# 7. 가상환경 활성화

Git Bash 기준:

```bash
source .venv/Scripts/activate
```

활성화 후 터미널에 보통:

```text
(.venv)
```

같은 표시가 나타난다.

---

## 현재 사용 중인 Python 확인

```bash
which python
```

현재 `python` 명령어가 실제로 어떤 Python 실행 파일을 사용하는지 확인한다.

가상환경 활성화 후 예:

```text
/project/.venv/Scripts/python
```

---

## 가상환경 종료

```bash
deactivate
```

---

## source란?

```bash
source
```

는 환경변수를 개선하는 명령어가 아니다.

현재 Shell에서 지정한 스크립트를 실행하는 명령어다.

따라서:

```bash
source .venv/Scripts/activate
```

는:

```text
현재 Shell에서
가상환경 활성화 스크립트를 실행
```

한다는 의미다.

---

# 8. uv를 사용할 때 가상환경 활성화는 필수인가?

반드시 직접 활성화할 필요는 없다.

예:

```bash
uv run main.py
```

처럼 사용하면 uv가 프로젝트의 가상환경을 알아서 사용한다.

따라서:

```text
직접 활성화
source .venv/Scripts/activate

또는

uv를 통해 실행
uv run main.py
```

두 가지 방법을 사용할 수 있다.

# 10. Python 패키지 관리

## 패키지 설치

```bash
uv add fastapi
```

FastAPI를 프로젝트 의존성에 추가한다.

---

## 패키지 삭제

```bash
uv remove fastapi
```

프로젝트에서 FastAPI를 제거한다.

---

## 패키지 구조 확인

```bash
uv tree --depth 1
```

프로젝트가 사용하는 패키지와 의존성을 1단계 깊이까지 확인한다.

---

## 환경 동기화

```bash
uv sync
```

프로젝트 설정과 lock 파일을 기준으로 `.venv`의 패키지 상태를 맞춘다.

쉽게:

```text
pyproject.toml / uv.lock
        ↓
     uv sync
        ↓
.venv의 패키지 상태를 맞춤
```

# 13. Jupyter Cell

Jupyter에서는 코드 영역을 보통:

```text
Cell
```

이라고 부른다.

코드 Cell 예:

```python
import sys

print("Hello, World!")
print(sys.executable)
```

---

## sys.executable

```python
sys.executable
```

현재 Jupyter Notebook이 실제로 사용 중인 Python 실행 파일의 경로를 확인한다.

예:

```text
C:\project\.venv\Scripts\python.exe
```

이렇게 나오면 현재 프로젝트의 `.venv` Python을 사용하고 있다는 뜻이다.

> `sys.executble`이 아니라 `sys.executable`이 정확한 이름이다.

# 18. 변수 이름 규칙

## 숫자로 시작할 수 없음

```python
1_name = "Bae"
```

❌ 잘못된 변수명

```python
name_1 = "Bae"
```

✅ 가능

---

## 공백 사용 불가

```python
user name = "Bae"
```

❌

```python
user_name = "Bae"
```

✅

---

## 하이픈 `-` 사용 불가

```python
user-age = 30
```

❌

Python은 `-`를 빼기 연산자로 인식한다.

```python
user_age = 30
```

✅

---

## 예약어 사용 불가

다음과 같은 Python 예약어는 변수명으로 사용할 수 없다.

```text
if
else
def
class
for
while
return
```

예:

```python
if = 10
```

❌

# 19. Python 이름 작성 Convention

## snake_case

Python의 일반 변수명과 함수명에 자주 사용한다.

```python
user_name = "Bae"
total_price = 5000
value_list = [1, 2, 3]
```

형태:

```text
단어_단어
```

---

## PascalCase

클래스 이름 등에 주로 사용한다.

```text
UserName
ValueList
UserAccount
```

형태:

```text
첫 단어부터 각 단어의 첫 글자를 대문자로 작성
```

---

## camelCase

```text
userName
valueList
totalPrice
```

첫 단어는 소문자로 시작하고 이후 단어의 첫 글자를 대문자로 작성한다.

Python에서는 일반 변수명에 보통 `snake_case`를 많이 사용한다.

# 20. Python 기본 자료형

| 자료형 | Python | 예 |
|---|---|---|
| 정수 | `int` | `25` |
| 실수 | `float` | `3.14` |
| 불리언 | `bool` | `True`, `False` |
| 문자열 | `str` | `"BaeYuSeong"` |
| 리스트 | `list` | `[1, 2, 3, 4]` |

예:

```python
age = 25
pi = 3.14
is_alive = True
user_name = "BaeYuSeong"
grade_type = [1, 2, 3, 4]
```

각각:

```text
age        → int
pi         → float
is_alive   → bool
user_name  → str
grade_type → list
```

Array
```

List
```
