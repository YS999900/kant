## 1. 선형회귀 — Linear Regression

선형회귀는 입력 데이터와 정답 데이터 사이의 관계를 직선으로 표현하여 새로운 값을 예측하는 머신러닝 알고리즘이다.

이번 실습에서는 학생의 공부 시간을 이용해 시험 성적을 예측하는 모델을 만들었다.

### 선형회귀 공식

\[
\hat{y} = wx + b
\]

| 기호 | 의미 |
|---|---|
| `x` | 입력 데이터(공부 시간) |
| `ŷ` | 모델이 예측한 성적 |
| `w` | 기울기(Weight) |
| `b` | 절편(Bias) |

기울기는 공부 시간이 1시간 증가할 때 예측 성적이 얼마나 변하는지를 나타낸다.

절편은 공부 시간이 0시간일 때 회귀직선이 예측하는 성적이다.

**핵심:** 선형회귀는 입력값에 기울기를 곱하고 절편을 더해 결과를 예측한다.

## 3. 독립변수(X)와 종속변수(y) 분리

머신러닝에서는 모델에 입력할 데이터와 예측할 정답 데이터를 구분한다.

```python
# 입력 데이터 (Feature)
X = df[["hours"]]

# 정답 데이터 (Target)

```

| 구분 | 의미 | 자료형 |
|---|---|---|
| `X` | 입력 데이터, 독립변수 | 2차원 DataFrame |
| `y` | 정답 데이터, 종속변수 | 1차원 Series |

### 대괄호 차이

```python
df["hours"]    # 1차원 Series
df[["hours"]]  # 2차원 DataFrame
```

`sklearn`의 일반적인 입력 형식은 `(샘플 수, 특성 수)` 형태의 2차원 데이터이다.

따라서 입력변수 `X`에는 대괄호를 두 겹 사용했다.

**핵심:** `X`는 모델이 참고할 입력 데이터이고, `y`는 모델이 예측해야 할 정답 데이터이다.

## 4. 모델 생성 및 학습


객체를 생성한 뒤 `fit()`을 실행하면 데이터를 바탕으로 적절한 기울기와 절편을 학습한다.

## 5. 기울기와 절편 확인

학습된 선형회귀 모델의 기울기와 절편을 확인했다.

| `model.coef_[0]` | 첫 번째 입력변수의 기울기 |

| `:.2f` | 소수점 둘째 자리까지 출력 |

입력변수가 여러 개라면 `coef_`에는 각 입력변수에 대응하는 기울기가 저장된다.

이번 실습에서는 입력변수가 공부 시간 하나이므로 `coef_[0]`을 사용했다.

## 8. MAE — 평균절대오차

MAE(Mean Absolute Error)는 실제값과 예측값의 차이를 절댓값으로 바꾸어 평균한 지표이다.

```python
from sklearn.metrics import mean_absolute_error

mae = mean_absolute_error(y, y_pred)

print(f"평균 절대 오차(MAE): {mae:.2f}")
```

### 공식

\[
MAE=\frac{1}{n}\sum_{i=1}^{n}|y_i-\hat{y}_i|
\]

### 특징

- 실제값과 예측값의 평균적인 차이를 나타낸다.
- 오차의 방향과 관계없이 크기만 계산한다.
- 값이 작을수록 예측 오차가 작다.
- 단위가 예측 대상과 같다.

**핵심:** MAE는 모델의 예측값이 실제값에서 평균적으로 얼마나 벗어났는지 보여준다.

## 9. MSE — 평균제곱오차

MSE(Mean Squared Error)는 실제값과 예측값의 차이를 제곱하여 평균한 지표이다.

```python
from sklearn.metrics import mean_squared_error

mse = mean_squared_error(y, y_pred)

print(f"평균 제곱 오차(MSE): {mse:.2f}")
```

### 공식

\[
MSE=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2
\]

### 특징

- 오차를 제곱하므로 큰 오차에 민감하다.
- 예측값과 실제값의 차이가 클수록 손실이 크게 증가한다.
- 값이 작을수록 예측 오차가 작다.
- 선형회귀 학습에서 대표적인 손실함수로 사용된다.

**핵심:** MSE는 큰 예측 오차에 더 큰 불이익을 주는 평가 지표이다.

## 10. R² — 결정계수

R²(R-squared)는 회귀 모델이 정답 데이터의 변동을 어느 정도 설명하는지 나타내는 지표이다.

```python
from sklearn.metrics import r2_score

r2 = r2_score(y, y_pred)

print(f"결정계수(R²): {r2:.2f}")
```

### R² 해석

| 값 | 의미 |
|---|---|
| `1` | 완벽한 예측 |
| `1`에 가까움 | 설명력이 높음 |
| `0` | 평균값 예측 기준 모델과 같은 수준 |
| 음수 | 평균값 예측보다 성능이 낮음 |

R²는 음수가 될 수도 있으며, 값이 높다고 해서 새로운 데이터에서도 반드시 좋은 예측을 보장하는 것은 아니다.

### 모델 평가 지표 비교

| 지표 | 의미 | 일반적인 평가 방향 |
|---|---|---|
| MAE | 평균 절대오차 | 낮을수록 좋음 |
| MSE | 평균 제곱오차 | 낮을수록 좋음 |
| R² | 모델 설명력 | 높을수록 좋음 |

**핵심:** 회귀 모델의 성능은 MAE, MSE, R² 등 여러 지표를 함께 확인해야 한다.

## 11. 경사하강법 — Gradient Descent

경사하강법은 손실함수의 값을 줄이는 방향으로 모델의 가중치와 절편을 반복적으로 조정하는 최적화 방법이다.

선형회귀 공식은 다음과 같다.

\[
\hat{y}=wx+b
\]

여기서 `w`와 `b`를 조정하여 실제값과 예측값의 차이를 줄이는 것이 학습의 목적이다.

### 손실함수 — Loss Function

손실함수는 모델이 예측한 결과와 실제 정답의 차이를 수치로 표현하는 함수이다.

이번 실습에서는 MSE를 사용했다.

경사하강법은 손실함수의 기울기 정보를 이용해 손실이 감소하는 방향으로 모델의 파라미터를 변경한다.

**핵심:** 경사하강법은 오차를 줄이기 위해 기울기와 절편을 반복적으로 업데이트하는 학습 방법이다.

## 12. BGD와 SGD의 차이

경사하강법은 가중치를 업데이트할 때 사용하는 데이터의 양에 따라 구분할 수 있다.

| 구분 | BGD | SGD |
|---|---|---|
| 이름 | Batch Gradient Descent | Stochastic Gradient Descent |
| 데이터 사용 | 전체 데이터 | 한 번에 하나의 샘플 |
| 가중치 업데이트 | 전체 데이터 기준 | 샘플별 업데이트 |
| 특징 | 상대적으로 안정적인 손실 변화 | 손실 변화에 변동이 발생할 수 있음 |
| 주의사항 | 데이터가 크면 계산 비용 증가 | 학습률과 데이터 순서의 영향 |

이번 실습에서는 `SGDRegressor`를 사용하여 경사하강법을 구현했다.

## 13. SGDRegressor — 확률적 경사하강법 모델 생성

```python
from sklearn.linear_model import SGDRegressor

sgd = SGDRegressor(
    loss="squared_error",
    learning_rate="constant",
    eta0=0.01,
    max_iter=1000,
    shuffle=False,
    random_state=42
)
```

### 매개변수 해석

| 매개변수 | 의미 |
|---|---|
| `loss="squared_error"` | 제곱오차 손실함수 사용 |
| `learning_rate="constant"` | 일정한 학습률 사용 |
| `eta0=0.01` | 초기 학습률 0.01 지정 |
| `max_iter=1000` | `fit()`의 최대 반복 횟수 설정 |
| `shuffle=False` | 학습 데이터 순서를 섞지 않음 |
| `random_state=42` | 난수 시드 지정 |

### 학습률 — Learning Rate

학습률은 모델의 파라미터를 한 번에 얼마나 변경할지 결정하는 값이다.

- 학습률이 너무 크면 최솟값을 지나치거나 학습이 불안정해질 수 있다.
- 학습률이 너무 작으면 학습 속도가 느려질 수 있다.
- 적절한 학습률을 설정하면 손실을 효율적으로 줄일 수 있다.

**핵심:** `SGDRegressor`는 데이터에 기반해 기울기와 절편을 반복적으로 업데이트하는 회귀 모델이다.

## 14. Epoch와 partial_fit() — 반복 학습

Epoch는 전체 학습 데이터를 한 번 학습하는 단위를 의미한다.

이번 실습에서는 전체 데이터를 1,000번 반복해서 학습했다.

```python
epochs = 1000

history = []

for epoch in range(epochs):
    sgd.partial_fit(X, y)

    y_pred = sgd.predict(X)

    mse = mean_squared_error(y, y_pred)

    history.append({
        "epoch": epoch + 1,
        "weight": sgd.coef_[0],
        "bias": sgd.intercept_[0],
        "mse": mse
    })
```

### 코드 실행 과정

1. `range(epochs)`로 1,000번 반복한다.
2. `partial_fit(X, y)`으로 모델을 추가 학습한다.
3. `predict(X)`로 현재 모델의 예측값을 계산한다.
4. `mean_squared_error()`로 현재 MSE를 계산한다.
5. `history.append()`로 현재 학습 결과를 저장한다.

### fit()과 partial_fit() 비교

| 메서드 | 역할 |
|---|---|
| `fit()` | 모델 학습 수행 |
| `partial_fit()` | 기존 상태에서 추가 학습 수행 |
| `predict()` | 현재 모델의 예측값 계산 |

`partial_fit()`은 학습 상태를 유지하면서 반복적으로 학습할 때 사용할 수 있다.

이번 실습에서는 한 번의 `partial_fit(X, y)` 호출마다 주어진 학습 데이터를 한 차례 학습하도록 반복문을 구성했다.

**핵심:** `partial_fit()`을 반복 호출하면 가중치가 변화하는 학습 과정을 관찰할 수 있다.

## 15. history — 학습 과정 기록

모델의 학습 과정을 분석하기 위해 매 Epoch의 결과를 리스트에 저장했다.

```python
history.append({
    "epoch": epoch + 1,

})
```

| `bias` | 현재 절편 |
| `mse` | 현재 평균제곱오차 |

### DataFrame으로 변환

```python
history_df = pd.DataFrame(history)
```

리스트에 저장된 학습 기록을 DataFrame으로 변환하여 표 형태로 분석했다.

### 특정 Epoch 조회

```python
history_df[

```

### isin()의 역할

`isin()`은 컬럼 값이 지정한 목록에 포함되어 있는지 확인하는 메서드이다.

예를 들어 `epoch`가 1, 5, 10, 50 등에 해당하는 행만 조회할 수 있다.

**핵심:** 학습 기록을 저장하면 모델의 파라미터와 오차가 시간에 따라 어떻게 변화하는지 분석할 수 있다.

## 16. 손실함수 변화 시각화


### 코드 해석

|---|---|
| `history_df["epoch"]` | X축에 사용할 학습 반복 횟수 |

**핵심:** 학습 손실 그래프는 모델의 학습 진행 상태와 수렴 여부를 살펴보는 데 도움이 된다.

## 19. 다중 선형회귀 — Multiple Linear Regression

다중 선형회귀는 두 개 이상의 독립변수를 사용하여 하나의 종속변수를 예측하는 모델이다.

이번 실습에서는 공부 시간, 수면 시간, 문제풀이 개수를 이용해 시험 성적을 분석했다.

### 데이터 생성

```python
df = pd.DataFrame({
    "study_hours":    [1, 2, 3, 4, 5, 2, 3, 5, 4, 1],
    "sleep_hours":    [6, 8, 5, 7, 8, 5, 8, 6, 6, 8],
    "practice_count": [10, 15, 20, 25, 30, 12, 28, 22, 32, 8],
    "score":          [47, 58, 60, 76, 87, 49, 73, 77, 79, 52]
})
```

### 주요 컬럼

| 컬럼 | 의미 |
|---|---|
| `study_hours` | 공부 시간 |
| `sleep_hours` | 수면 시간 |
| `practice_count` | 문제풀이 개수 |
| `score` | 시험 성적 |

### 다중 선형회귀 공식

\[
\hat{y}=w_1x_1+w_2x_2+w_3x_3+b
\]

각 입력변수에 서로 다른 기울기를 적용한 뒤, 그 결과를 합산하고 절편을 더해 예측한다.

**핵심:** 단순 선형회귀는 입력변수 하나를 사용하고, 다중 선형회귀는 입력변수 여러 개를 사용한다.

## 24. 실습 오류 및 수정 사항

오늘 작성한 코드에서 확인한 오류와 주의사항을 정리했다.

| 항목 | 원인 또는 주의사항 | 수정 및 확인 |
|---|---|---|
| `model = LinearRegression` | 클래스 자체를 변수에 저장 | `LinearRegression()` 사용 |
| `predictde_score` | 변수명 오타 | `predicted_score`로 수정 권장 |
| `Traing Loss` | 문자열 오타 | `Training Loss` |
| `plt.xlabel("Loss")` | X축이 Epoch인데 Loss로 표시 | `plt.xlabel("Epoch")` |
| MSE 출력 설명 | 평균 절대오차라고 잘못 표기 | `평균 제곱 오차` |
| R² 출력 설명 | 평균 절대오차라고 잘못 표기 | `결정계수` |
| `max_iter=1000` | `partial_fit()` 호출마다 1,000회 반복한다는 의미는 아님 | 반복 횟수는 별도의 `epochs`로 제어 |
| 학습 데이터 평가 | 학습에 사용한 데이터로 예측 성능을 계산 | 일반화 성능 평가 시 별도의 테스트 데이터 필요 |

### 추가 확인사항

- `LinearRegression()`과 `SGDRegressor()`는 모두 회귀 문제에 사용할 수 있다.
- `LinearRegression`은 일반적으로 최소제곱해를 구하는 방식으로 학습한다.
- `SGDRegressor`는 반복적인 가중치 업데이트를 통해 손실을 줄이는 방식으로 학습한다.
- `partial_fit()`은 이전 학습 상태를 유지하면서 추가 학습할 때 사용한다.
- SGD는 학습률과 데이터 순서에 따라 학습 과정이 달라질 수 있다.
- MAE와 MSE는 낮을수록 좋고 R²는 일반적으로 높을수록 좋다.
- 학습 데이터에서 높은 성능을 보였더라도 새로운 데이터에서 같은 성능이 보장되지는 않는다.
- 다중 선형회귀에서 입력변수가 늘어난다고 반드시 예측 성능이 향상되는 것은 아니다.
