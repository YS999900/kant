## 3. isnull() — 결측치 확인

결측치란 데이터가 비어 있거나 누락된 상태를 의미한다.

Pandas에서는 `NaN` 등의 형태로 표현된다.

```python
df.isnull().sum()
```

### 코드 실행 과정

1. `df.isnull()`은 각 셀의 값이 결측치인지 확인한다.
2. 결측치라면 `True`, 아니라면 `False`를 반환한다.
3. `.sum()`으로 각 컬럼의 `True` 개수를 계산한다.

### 나이가 비어 있는 승객 확인

```python
empty_age = df["age"].isnull()

print("나이 빈칸:", empty_age.sum(), "명")

df.loc[empty_age, ["sex", "age", "class"]].head()
```

### 코드 해석

| 코드 | 의미 |
|---|---|
| `df["age"]` | 나이 컬럼 선택 |
| `.isnull()` | 나이가 비어 있는지 확인 |
| `empty_age` | 결측치 여부를 저장한 변수 |
| `.sum()` | 결측치 개수 계산 |
| `df.loc[empty_age, ...]` | 나이가 비어 있는 승객만 선택 |
| `["sex", "age", "class"]` | 성별, 나이, 객실 등급 컬럼 선택 |

**핵심:** `isnull()`과 불리언 조건을 사용하면 결측치가 있는 데이터를 선택적으로 확인할 수 있다.

## 4. mean()과 median() — 평균과 중앙값

결측치를 처리하기 전에 나이 데이터의 평균과 중앙값을 계산했다.

```python
print("평균:", round(df["age"].mean(), 2))
print("중앙값:", round(df["age"].median(), 2))
```

| 메서드 | 역할 |
|---|---|
| `mean()` | 평균 계산 |
| `median()` | 중앙값 계산 |
| `round(값, 2)` | 소수점 둘째 자리까지 반올림 |

### 평균과 중앙값의 차이

데이터가 다음과 같다고 가정한다.

```python
ages = [10, 20, 30, 40, 100]
```

- 평균: `(10 + 20 + 30 + 40 + 100) / 5 = 40`
- 중앙값: `30`

평균은 모든 값의 영향을 받지만 중앙값은 정렬했을 때 가운데 위치한 값이므로 극단적인 값의 영향을 상대적으로 적게 받는다.

**핵심:** 결측치를 어떤 값으로 채울지 판단할 때 평균과 중앙값 등의 대표값을 활용할 수 있다.

## 5. fillna() — 평균값으로 결측치 처리

`fillna()`는 비어 있는 값을 지정한 값으로 채우는 메서드이다.

이번 실습에서는 나이의 결측치를 평균 나이로 채웠다.

```python
mean_age = df["age"].mean()

df.loc[:, "age"] = df["age"].fillna(mean_age)
```

### 코드 해석

| 코드 | 의미 |
|---|---|
| `mean_age` | 나이 평균을 저장한 변수 |
| `df["age"].fillna(mean_age)` | 나이 결측치를 평균값으로 채운 결과 반환 |
| `df.loc[:, "age"]` | 모든 행의 age 컬럼 선택 |
| `=` | 처리 결과를 원래 컬럼에 저장 |

### loc[]의 구조

```python
df.loc[행 조건, 컬럼 이름]
```

예를 들어:

```python
df.loc[:, "age"]
```

- `:` : 모든 행
- `"age"` : 나이 컬럼

결측치를 채운 후에는 다음 코드로 확인할 수 있다.

```python
df["age"].isnull().sum()
```

**핵심:** `fillna()`는 결측치를 채운 결과를 반환하며, 이를 기존 컬럼에 다시 저장해야 데이터가 변경된다.

## 6. mode() — 최빈값으로 결측치 처리

최빈값은 데이터에서 가장 많이 등장한 값이다.

이번에는 승객들의 탑승 항구 데이터에 적용했다.

```python
df["embark_town"].value_counts(dropna=False)
```

`value_counts()`는 각 값의 등장 횟수를 계산한다.

`dropna=False`를 사용하면 결측치도 개수에 포함된다.

### 최빈값 구하기

```python
mode_town = df["embark_town"].mode()[0]

print("최빈값:", mode_town)
```

### 코드 해석

1. `df["embark_town"]`으로 탑승 항구 컬럼을 선택한다.
2. `.mode()`로 가장 많이 등장한 값을 구한다.
3. `[0]`으로 첫 번째 최빈값을 선택한다.
4. `mode_town` 변수에 저장한다.

### 최빈값으로 결측치 채우기

```python
df.loc[:, "embark_town"] = df["embark_town"].fillna(mode_town)
```

결측치 처리 후 확인:

```python
df["embark_town"].value_counts(dropna=False)
```

### 평균·중앙값·최빈값 비교

| 구분 | 역할 | 활용 예시 |
|---|---|---|
| `mean()` | 평균 | 나이, 금액 |
| `median()` | 중앙값 | 극단적인 값이 있는 수치 데이터 |
| `mode()` | 최빈값 | 지역, 성별, 항구 등 범주형 데이터 |

**핵심:** 수치형 데이터에는 평균이나 중앙값을, 범주형 데이터에는 최빈값을 활용할 수 있다. 단, 어떤 방법이 적절한지는 데이터의 특성과 분석 목적에 따라 달라진다.

## 9. add_categories()와 fillna() — 범주형 결측치 처리

이번 실습에서는 `deck` 컬럼의 결측치를 `"Unknown"`으로 채웠다.

```python
df["deck"] = df["deck"].cat.add_categories("Unknown").fillna("Unknown")
```

### 코드를 단계별로 분해

**1단계: 범주 목록 확인**

```python
df["deck"].cat.categories
```

**2단계: 새로운 범주 추가**

```python
df["deck"].cat.add_categories("Unknown")
```

이 단계에서는 `"Unknown"`을 사용할 수 있는 범주로 추가할 뿐, 기존 결측치가 자동으로 변경되지는 않는다.

**3단계: 결측치 채우기**

```python
.fillna("Unknown")
```

**4단계: 결과 저장**

```python
df["deck"] = ...
```

### 여러 줄로 표현하면

```python
step1 = df["deck"].cat.add_categories("Unknown")
step2 = step1.fillna("Unknown")

df["deck"] = step2
```

### 처리 결과 확인

```python
print(df["deck"].cat.categories.to_list())
print(df["deck"].value_counts())
```

**핵심:** 범주형 데이터에서 기존 범주에 없는 값으로 결측치를 채우려면 먼저 해당 범주를 추가해야 한다.

## 10. quantile() — 사분위수 계산

사분위수는 데이터를 크기순으로 정렬한 뒤 분포를 네 부분으로 나누는 기준값이다.

```python
print(df["fare"].quantile([0.25, 0.5, 0.75]))
```

또는 다음처럼 조회할 수 있다.

```python
df["fare"].describe()[["25%", "50%", "75%"]]
```

### 사분위수의 의미

| 구분 | 의미 |
|---|---|
| Q1 (25%) | 제1사분위수 |
| Q2 (50%) | 중앙값 |
| Q3 (75%) | 제3사분위수 |
| IQR | Q3 - Q1 |

**핵심:** 사분위수는 데이터의 분포를 파악하고 이상치를 탐지할 때 활용한다.

## 11. IQR을 활용한 이상치 탐지

이상치(Outlier)는 다른 데이터에 비해 지나치게 크거나 작은 값을 의미한다.

이번 실습에서는 승선 요금(`fare`)을 기준으로 이상치를 확인했다.

### IQR 계산

```python
q1 = df["fare"].quantile(0.25)
q3 = df["fare"].quantile(0.75)

iqr = q3 - q1
upper = q3 + 1.5 * iqr
```

### IQR 공식

\[
IQR = Q3 - Q1
\]

\[
상한값 = Q3 + 1.5 \times IQR
\]

일반적으로 아래쪽 경계도 계산할 수 있다.

\[
하한값 = Q1 - 1.5 \times IQR
\]

### 계산 결과 출력

```python
print(
    f"Q1={q1:.2f}, Q3={q3:.2f} "
    f"IQR={iqr:.2f} UPPER={upper:.2f}"
)
```

여기서 `:.2f`는 숫자를 소수점 둘째 자리까지 표시하는 형식 지정자이다.

### 이상치 개수 확인

```python
print("이상 승선요금:", (df["fare"] > upper).sum(), "명")
```

### 코드 실행 과정

1. `df["fare"] > upper`로 상한값보다 높은 요금을 찾는다.
2. 조건을 만족하는 값은 `True`가 된다.
3. `.sum()`으로 `True` 개수를 계산한다.

**핵심:** IQR은 데이터의 중간 50% 범위를 나타내며, 이를 활용해 극단적인 값을 탐지할 수 있다.

## 12. 이상치 조회 및 제거

이번 실습에서는 승선 요금이 512보다 작은 데이터만 남기는 방법을 사용했다.

```python
df[df["fare"] > 512]
```

위 코드는 승선 요금이 512보다 높은 행을 조회한다.

### 이상치 제거

```python
before = len(df)

df = df[df["fare"] < 512].copy()

print(before, "=>", len(df))
```

### 코드 해석

| 코드 | 의미 |
|---|---|
| `len(df)` | DataFrame의 행 개수 |
| `df["fare"] < 512` | 요금이 512 미만인지 확인 |
| `df[조건식]` | 조건을 만족하는 행만 선택 |
| `.copy()` | 선택한 데이터를 별도의 DataFrame으로 복사 |
| `df = ...` | 필터링 결과를 기존 변수에 저장 |

### 주의할 점

실습에서 계산한 `upper`는 IQR 기반 상한값이고, `512`는 별도로 지정한 고정 기준값이다.

따라서 `fare < 512`는 IQR 기준으로 판정된 모든 이상치를 제거하는 코드와 동일하지 않다.

IQR 상한값 기준으로 제거하려면 다음과 같이 작성할 수 있다.

```python
df = df[df["fare"] <= upper].copy()
```

**핵심:** 이상치를 탐지하는 것과 제거하는 것은 서로 다른 작업이며, 제거 기준은 분석 목적에 맞게 설정해야 한다.

## 13. duplicated() — 중복 데이터 확인

`duplicated()`는 중복된 행을 확인하는 메서드이다.

```python
print("중복 행:", df.duplicated().sum(), "개")
```

기본적으로 모든 컬럼 값이 같은 행을 중복으로 판단한다.

### 중복 데이터 전체 조회

```python
df[df.duplicated(keep=False)].sort_values(["fare", "age"]).head(5)
```

### 코드 해석

| 코드 | 의미 |
|---|---|
| `df.duplicated()` | 중복된 행 확인 |
| `keep=False` | 중복 그룹에 속한 모든 행을 중복으로 표시 |
| `df[조건식]` | 중복된 행 선택 |
| `sort_values(["fare", "age"])` | 요금과 나이 순서로 정렬 |
| `head(5)` | 앞의 5행 출력 |

### duplicated() 옵션

| 옵션 | 동작 |
|---|---|
| `keep="first"` | 첫 번째 행을 제외한 중복 행 표시 |
| `keep="last"` | 마지막 행을 제외한 중복 행 표시 |
| `keep=False` | 중복된 모든 행 표시 |

**핵심:** `duplicated()`는 중복 여부를 확인하며, 실제로 중복 데이터를 제거하려면 별도의 처리가 필요하다.

## 14. platform — 운영체제 확인

운영체제에 따라 사용 가능한 글꼴이 다를 수 있으므로 `platform`을 사용해 운영체제를 확인했다.

import platform

if os_name == "Windows":

**핵심:** 운영체제에 맞는 한글 글꼴을 지정하면 그래프의 한글이 깨지는 문제를 예방할 수 있다.

## 15. Matplotlib — 나이 분포 히스토그램

Matplotlib은 Python에서 그래프를 생성하는 라이브러리이다.

이번에는 Titanic 승객들의 나이 분포를 히스토그램으로 표현했다.

```python
fig, ax = plt.subplots(figsize=(6, 4))

ax.hist(
    df["age"],
    bins=20,
    color="blue",
    edgecolor="black"
)

ax.set_title("나이분포")
ax.set_xlabel("나이(세)")
```

### 코드 해석

| 코드 | 의미 |
|---|---|
| `plt.subplots()` | Figure와 Axes 생성 |
| `fig` | 그래프 전체 영역 |
| `ax` | 실제 그래프를 그리는 영역 |
| `figsize=(6, 4)` | 그래프 크기 설정 |
| `ax.hist()` | 히스토그램 생성 |
| `df["age"]` | 나이 데이터 |
| `bins=20` | 데이터를 20개 구간으로 나눔 |
| `color="blue"` | 막대 내부 색상 |
| `edgecolor="black"` | 막대 테두리 색상 |
| `set_title()` | 그래프 제목 설정 |
| `set_xlabel()` | X축 이름 설정 |

### 히스토그램의 특징

히스토그램은 수치형 데이터가 어떤 구간에 많이 분포하는지 확인할 때 사용한다.

- X축: 나이 구간
- Y축: 해당 구간에 포함된 승객 수

**핵심:** 히스토그램을 이용하면 평균값만으로는 확인하기 어려운 데이터의 분포 형태를 시각적으로 파악할 수 있다.

## 16. 실습 오류 및 수정 사항

오늘 작성한 코드에서 확인할 수 있는 오타와 주의사항을 정리했다.

| 오류 또는 주의사항 | 원인 | 수정 또는 확인 방법 |
|---|---|---|
| `fellna` | 주석의 함수명 오타 | `fillna` |
| `AqqleGothic` | macOS 글꼴 이름 오타 | `AppleGothic` |
| 범주 추가 중복 실행 | 이미 존재하는 범주를 다시 추가하려는 경우 | 범주 목록 확인 후 추가 |
| 평균으로 결측치 채우기 | 데이터 분포에 따라 평균값이 적절하지 않을 수 있음 | 평균과 중앙값 비교 |
| `fare < 512` | IQR 상한값이 아닌 고정 기준 사용 | 이상치 제거 기준 명확히 구분 |
| `duplicated()` 결과 | 값이 같은 행이 실제로는 서로 다른 승객일 수 있음 | 중복 제거 전 데이터 의미 확인 |
| `empty_age` 재사용 | 결측치 처리 전에 만든 조건이 유지됨 | 현재 결측치 상태를 보려면 다시 계산 |

### 추가 확인사항

- `fillna()`로 결측치를 채우면 원래의 누락 정보를 구분하기 어려울 수 있다.
- `mode()[0]`은 최빈값이 여러 개일 때 첫 번째 값을 선택한다.
- `category` 자료형에서는 새 값을 사용하기 전에 범주 목록에 포함되어 있는지 확인해야 한다.
- IQR 기준으로 탐지된 값이 반드시 잘못된 데이터라는 뜻은 아니다.
- `copy()`는 필터링한 결과를 별도의 DataFrame으로 관리할 때 유용하다.
- `duplicated()`로 값이 같은 행을 찾았더라도 실제 데이터의 의미를 확인한 뒤 삭제 여부를 결정해야 한다.
