## 1. 선형회귀 (Linear Regression)

선형회귀는 데이터의 관계를 가장 잘 설명하는 직선을 찾아 새로운 값을 예측하는 머신러닝 알고리즘이다.

### 선형회귀 구성 요소

- Feature(X): 입력 데이터, 독립변수
- Target(y): 정답 데이터, 종속변수
- Weight(w): 가중치, 기울기
- Bias(b): 편향, 절편

선형회귀 공식: `y = wx + b`

### 모델 학습 및 예측

```python
from sklearn.linear_model import LinearRegression

X = df[["hours"]]
y = df["scores"]

model = LinearRegression()
model.fit(X, y)

new_data = pd.DataFrame({"hours": [6]})
prediction = model.predict(new_data)
```

- `LinearRegression()` : 선형회귀 모델 객체 생성
- `fit()` : 입력 데이터와 정답 데이터를 이용한 모델 학습
- `predict()` : 학습된 모델을 이용한 새로운 값 예측
- `coef_` : 학습된 가중치(기울기)
- `intercept_` : 학습된 편향(절편)

공부 시간을 입력 데이터로 사용하여 시험 성적을 예측하고, 실제 데이터와 회귀 직선을 그래프로 시각화하였다.

## 2. 모델 평가 지표

모델의 실제값과 예측값을 비교하여 모델의 성능을 평가한다.

| 평가 지표 | 의미 |
|---|---|
| MAE | 절대 오차의 평균 |
| MSE | 제곱 오차의 평균 |
| R² | 모델의 설명력을 나타내는 결정계수 |

```python
from sklearn.metrics import mean_absolute_error
from sklearn.metrics import mean_squared_error
from sklearn.metrics import r2_score

mae = mean_absolute_error(y, y_pred)
mse = mean_squared_error(y, y_pred)
r2 = r2_score(y, y_pred)
```

- MAE는 오차의 크기를 직관적으로 확인할 수 있다.
- MSE는 오차를 제곱하기 때문에 큰 오차에 더 민감하게 반응한다.
- R²는 1에 가까울수록 설명력이 높으며, 음수가 나오면 평균값으로 예측하는 기준 모델보다 성능이 낮다는 의미이다.

## 3. 경사하강법 (Gradient Descent)

경사하강법은 손실 함수의 값이 작아지는 방향으로 가중치와 절편을 반복적으로 조정하는 최적화 방법이다.

### 주요 개념

- Loss Function: 실제값과 예측값의 차이를 수치로 표현하는 함수
- Learning Rate: 한 번 학습할 때 파라미터를 조정하는 크기
- Epoch: 전체 학습 데이터를 한 번 학습하는 단위

### 경사하강법의 종류

| 종류 | 학습 방식 |
|---|---|
| BGD | 전체 데이터를 사용하여 가중치 갱신 |
| SGD | 데이터 한 개씩 사용하여 가중치 갱신 |

### SGDRegressor 실습

```python
from sklearn.linear_model import SGDRegressor

sgd = SGDRegressor(
    loss="squared_error",
    learning_rate="constant",
    eta0=0.01,
    max_iter=1000,
    random_state=42
)
```

- `loss` : 사용할 손실 함수
- `learning_rate` : 학습률 적용 방식
- `eta0` : 초기 학습률
- `max_iter` : 최대 학습 반복 횟수
- `random_state` : 난수 시드 고정

`partial_fit()`을 활용하여 반복적으로 학습을 진행하고, 각 Epoch의 학습 결과를 리스트에 저장하였다.

```python
history = []

for epoch in range(1000):
    sgd.partial_fit(X, y)
    y_pred = sgd.predict(X)

    history.append({
        "epoch": epoch + 1,
        "weight": sgd.coef_[0],
        "bias": sgd.intercept_[0],
        "mse": mean_squared_error(y, y_pred)
    })
```

학습 기록을 데이터프레임으로 변환하고 손실값, 가중치, 절편의 변화를 그래프로 확인하였다.

## 4. 다중 선형회귀 (Multiple Linear Regression)

단순 선형회귀는 하나의 입력 특성을 사용하지만, 다중 선형회귀는 여러 입력 특성을 사용하여 하나의 결과를 예측한다.

회귀 공식: `y = w1*x1 + w2*x2 + w3*x3 + b`

### 입력 데이터 구성

```python
features = [
    "study_hours",
    "sleep_hours",
    "practice_count"
]

X = df[features]
y = df["score"]

model = LinearRegression()
model.fit(X, y)
```

공부 시간, 수면 시간, 문제 풀이 횟수를 이용하여 시험 성적을 예측하였다.

- 입력 특성이 3개이므로 가중치도 3개가 생성된다.
- `corr()`과 `sns.heatmap()`을 사용하여 특성 간 상관관계를 확인하였다.
- 학습된 가중치를 회귀 공식에 직접 대입하여 `predict()`의 계산 원리를 확인하였다.

## 5. 학습 데이터와 테스트 데이터 분리

전체 데이터를 학습에 사용하면 새로운 데이터에 대한 예측 성능을 객관적으로 평가하기 어렵다.

이를 해결하기 위해 학습 데이터와 테스트 데이터를 분리한다.

```python
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.3,
    random_state=42
)
```

- `X_train` : 학습용 입력 데이터
- `X_test` : 테스트용 입력 데이터
- `y_train` : 학습용 정답 데이터
- `y_test` : 테스트용 정답 데이터
- `test_size=0.3` : 전체 데이터의 30%를 테스트에 사용

```python
model.fit(X_train, y_train)
test_pred = model.predict(X_test)
```

70%의 데이터로 모델을 학습하고, 학습에 사용하지 않은 30%의 데이터로 모델의 예측 성능을 평가하였다.

## 6. 특성 스케일링 (Feature Scaling)

서로 다른 단위와 크기를 가진 데이터를 비슷한 척도로 변환하는 데이터 전처리 과정이다.

특히 경사하강법을 사용할 때 특성별 데이터 크기의 차이가 학습에 영향을 줄 수 있다.

### StandardScaler

데이터의 평균을 0, 표준편차를 1로 변환하는 표준화 방법이다.

```python
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()

X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)
```

- `fit()` : 데이터의 평균과 표준편차 계산
- `transform()` : 계산된 기준으로 데이터 변환
- `fit_transform()` : 기준 계산과 데이터 변환을 동시에 실행

테스트 데이터는 새로운 기준을 계산하지 않고 학습 데이터에서 구한 평균과 표준편차를 사용해야 한다.

표준화된 데이터를 `SGDRegressor`에 적용하여 다중 선형회귀 모델을 학습하였다.

## 7. KNN (K-Nearest Neighbors) 기초

KNN은 새로운 데이터와 가까운 K개의 데이터를 찾아 분류하거나 값을 예측하는 알고리즘이다.

이번 실습에서는 KNN을 학습하기 위한 얼굴 이미지 데이터를 불러오고 데이터의 구조를 분석하였다.

### 얼굴 데이터 불러오기

```python
from sklearn.datasets import fetch_olivetti_faces

faces = fetch_olivetti_faces(data_home="./datasets")

print(faces.images.shape)
print(faces.target.shape)
print(np.unique(faces.target))
```

### 얼굴 데이터 구조

| 항목 | 내용 |
|---|---|
| 전체 이미지 | 400장 |
| 사람 수 | 40명 |
| 인물당 이미지 | 10장 |
| 이미지 크기 | 64 × 64 픽셀 |
| 이미지당 픽셀 수 | 4,096개 |
| 픽셀값 범위 | 0~1 |

- `shape` : 데이터의 배열 구조 확인
- `np.unique()` : 중복을 제거한 고유한 값 확인
- `faces.images` : 얼굴 이미지 데이터
- `faces.target` : 각 이미지에 해당하는 인물 번호

### 이미지 시각화

```python
plt.imshow(faces.images[0], cmap="grey", vmin=0, vmax=1)
plt.title(f"Person {faces.target[0]}")
plt.axis("off")
plt.show()
```

- `imshow()` : 배열 데이터를 이미지로 출력
- `cmap="grey"` : 흑백 이미지로 표시
- `vmin`, `vmax` : 색상 표현의 최솟값과 최댓값
- `axis("off")` : 그래프의 축 숨기기

### 이미지 픽셀값 확인

```python
corner = faces.images[0][20:28, 20:28]

fig, ax = plt.subplots(figsize=(5, 5))
ax.imshow(corner, cmap="grey", vmin=0, vmax=1)

for r in range(8):
    for c in range(8):
        v = corner[r, c]
        ax.text(c, r, f"{v:.1f}")

plt.show()
```

배열 슬라이싱을 사용하여 이미지의 일부를 8×8 크기로 추출하고, 이중 반복문을 이용하여 각 픽셀의 밝기값을 확인하였다.

이미지는 숫자 배열로 구성되어 있으며, 픽셀값이 0에 가까울수록 어둡고 1에 가까울수록 밝게 표현된다.

### 동일 인물의 이미지 추출

```python
def show_person(person):
    pics = faces.images[faces.target == person]

    fig, axes = plt.subplots(1, 10, figsize=(15, 2))

    for ax, img in zip(axes, pics):
        ax.imshow(img, cmap="grey", vmin=0, vmax=1)
        ax.axis("off")

    plt.show()

show_person(0)
show_person(7)
```

불리언 인덱싱을 사용하여 특정 인물의 이미지 10장을 추출하고, `zip()`을 활용하여 여러 그래프 영역에 이미지를 출력하였다.
