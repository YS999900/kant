# TIL - 2026.11.27 | 머신러닝 로지스틱 회귀 (Logistic Regression)

## 1. 오늘의 학습 내용

로지스틱 회귀를 활용하여 학생의 공부 시간, 수면 시간, 문제 풀이 횟수를 기반으로 시험 합격 여부와 합격 확률을 예측하는 모델을 구현했다.

## 2. 주요 학습 개념

### 데이터 생성 및 분리
- `pd.DataFrame()`을 활용하여 학생 10명의 데이터 생성
- `X`: 공부 시간, 수면 시간, 문제 풀이 횟수
- `y`: 시험 점수 60점 이상이면 True, 미만이면 False
- 선형회귀는 연속적인 수치를 예측하고, 로지스틱 회귀는 분류에 사용한다.

### 학습용 및 테스트용 데이터 분리
- `train_test_split()` : 학습용 데이터와 테스트용 데이터 분리
- `test_size=0.3` : 학습 70%, 테스트 30%
- `random_state=42` : 동일한 데이터 분리 결과 재현
- `stratify=y` : 합격과 불합격의 비율을 최대한 유지하며 분리

### 데이터 표준화
- `StandardScaler()` : 특성마다 다른 데이터의 스케일을 조정
- `fit_transform()` : 학습 데이터의 평균과 표준편차를 계산하고 변환
- `transform()` : 학습 데이터에서 계산한 기준으로 테스트 및 새로운 데이터 변환
- 데이터 누수를 방지하기 위해 테스트 데이터에는 `fit()`을 사용하지 않는다.

### 모델 생성 및 학습
- `LogisticRegression()` : 로지스틱 회귀 모델 생성
- `max_iter=1000` : 최대 반복 학습 횟수 설정
- `model.fit()` : 입력 데이터와 정답 데이터를 활용하여 모델 학습
- `model.classes_` : 분류 클래스 확인
- `model.coef_` : 각 입력 특성의 가중치 확인

### 새로운 데이터 예측
- `predict()` : 합격 또는 불합격 예측
- `predict_proba()` : 각 클래스에 속할 확률 예측
- `columns=X.columns` : 기존 학습 데이터와 동일한 컬럼 이름 및 순서 적용
- 새로운 데이터도 학습 데이터와 동일한 기준으로 표준화해야 한다.

### 모델 평가
- `accuracy_score()` : 전체 예측 중 정답을 맞힌 비율 계산
- `confusion_matrix()` : 실제 정답과 예측 결과를 비교하는 혼동행렬

| 구분 | 예측 불합격 | 예측 합격 |
|---|---|---|
| 실제 불합격 | TN | FP |
| 실제 합격 | FN | TP |

## 3. 전체 학습 흐름

데이터 생성 → X, y 분리 → 학습·테스트 데이터 분리 → 표준화 → 모델 생성 → 모델 학습 → 새로운 데이터 예측 → 모델 평가

## 4. 오늘의 핵심 정리

- 로지스틱 회귀는 이름에 회귀가 들어가지만 분류 알고리즘이다.
- 합격 여부뿐만 아니라 합격 확률도 예측할 수 있다.
- 학습, 테스트, 새로운 데이터의 표준화 기준은 동일해야 한다.
- 모델 평가는 학습에 사용하지 않은 데이터로 진행해야 한다.

## 5. 느낀 점 및 복습할 내용

선형회귀와 로지스틱 회귀의 차이를 이해하고, 데이터 전처리부터 모델 학습, 예측, 평가까지 머신러닝의 전체적인 흐름을 실습했다.

앞으로 표준화의 원리와 `fit_transform()` 및 `transform()`의 차이, 가중치의 의미, 혼동행렬을 활용한 모델 평가 방법을 추가로 복습할 예정이다.
