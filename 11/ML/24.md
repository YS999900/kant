## 2. sample() — 무작위 데이터 추출

Pandas의 `sample()`은 데이터에서 지정한 개수의 행을 무작위로 추출하는 메서드이다.

```python
sample_df = df.sample(10, random_state=42)
```

### 코드 해석

| 코드 | 의미 |
|---|---|
| `df` | 전체 데이터 |
| `.sample(10)` | 무작위로 10행 추출 |
| `random_state=42` | 무작위 결과를 재현하기 위한 시드 지정 |
| `sample_df` | 추출한 데이터를 저장할 변수 |

### random_state의 역할

컴퓨터에서 사용하는 일반적인 난수 생성기는 정해진 알고리즘을 이용한다.

`random_state`는 난수 생성의 초기 상태를 지정하는 역할을 한다.

```python
df.sample(10, random_state=42)
```

동일한 데이터와 동일한 조건에서 실행하면 같은 표본을 얻을 수 있다.

반면 다른 시드를 사용하면 표본이 달라질 수 있다.

**핵심:** `random_state`를 고정하면 무작위 추출 결과를 재현할 수 있어 실험 결과를 비교하기 쉽다.

## 3. 상관계수 — 두 변수의 관계 분석

상관계수(Correlation Coefficient)는 두 변수 사이의 선형 관계가 어느 정도인지를 나타낸다.

Pandas에서는 `corr()`을 사용하여 상관계수를 계산할 수 있다.

```python
df["area"].corr(df["price"])
```

### 상관계수 범위

상관계수는 -1에서 1 사이의 값을 가진다.

| 상관계수 | 의미 |
|---|---|
| 1에 가까움 | 강한 양의 선형 관계 |
| 0에 가까움 | 선형 관계가 약함 |
| -1에 가까움 | 강한 음의 선형 관계 |

### 학습 결과

```text
상관계수: 0.8963336215680755
```

약 0.896으로 강한 양의 상관관계를 나타냈다.

즉, 해당 데이터에서는 면적이 증가할수록 가격도 증가하는 경향이 강하게 나타났다.

단, 상관관계가 강하다고 해서 반드시 인과관계가 성립하는 것은 아니다.

**핵심:** 상관계수는 두 변수의 선형 관계를 수치로 표현하지만, 원인과 결과를 증명하지는 않는다.

## 4. 표본 크기에 따른 상관계수 변화

주택 데이터에서 전체 300개와 일부 10개를 이용해 계산한 상관계수를 비교했다.

### 실습 결과

| 데이터 | 상관계수 |
|---|---:|
| 전체 300채 | 0.08 |
| 일부 10채 | 0.89 |

전체 데이터에서는 상관계수가 0.08로 낮았지만, 일부 10채에서는 0.89로 높게 나타났다.

이는 일부 표본에서 관찰된 관계가 전체 데이터의 관계와 크게 다를 수 있음을 보여준다.

### 학습한 점

- 일부 데이터만 분석하면 우연히 강한 상관관계가 나타날 수 있다.
- 표본을 어떻게 선택하는지에 따라 분석 결과가 달라질 수 있다.
- 표본이 작을수록 결과가 불안정할 수 있다.
- 전체 데이터와 표본 데이터의 차이를 확인하는 것이 중요하다.

**핵심:** 상관계수를 해석할 때는 수치뿐 아니라 표본의 크기와 추출 방법도 확인해야 한다.

## 6. 선형회귀 — Linear Regression

선형회귀는 입력 변수와 예측 대상 사이의 관계를 직선으로 표현하는 머신러닝 방법이다.

이번에는 주택 면적을 이용해 주택 가격을 예측하는 모델을 학습했다.

### 선형회귀 기본 공식

\[
\hat{y} = wx + b
\]

| 기호 | 의미 |
|---|---|
| `x` | 입력값(주택 면적) |
| `ŷ` | 모델이 예측한 주택 가격 |
| `w` | 기울기(가중치) |
| `b` | 절편 |

### 기울기의 의미

면적이 1단위 증가할 때 예측 가격이 얼마나 변하는지 나타낸다.

### 절편의 의미

면적이 0일 때 직선이 예측하는 가격이다.

단, 면적 0인 주택이 실제 데이터에 없을 수도 있으므로 절편을 현실적인 주택 가격으로 직접 해석할 때는 주의해야 한다.

**핵심:** 선형회귀 모델은 입력값에 기울기를 곱하고 절편을 더해 예측값을 계산한다.

---

## 7. 학습된 기울기와 절편 확인

### 실습 결과

```text
기울기 w = 439.45870417134705
정답: 450

절편 b = 5926.680580056112
정답: 5000
```

학습한 모델의 기울기와 절편은 다음과 같다.

\[
\hat{y} = 439.46x + 5926.68
\]

이는 면적이 1단위 증가할 때 모델의 예측 가격이 약 439.46만큼 증가한다는 의미다.

### 모델 학습 결과 비교

| 항목 | 학습 결과 | 데이터 생성에 사용한 기준값 |
|---|---:|---:|
| 기울기(w) | 439.46 | 450 |
| 절편(b) | 5,926.68 | 5,000 |

실습에서는 모델이 기준값과 정확히 일치하지 않았지만 비교적 가까운 값을 학습했다.

이는 데이터에 잡음이나 특이값 등이 포함되어 있을 때 학습된 결과가 실제 생성 기준과 달라질 수 있음을 보여준다.

**핵심:** 머신러닝 모델은 주어진 데이터를 바탕으로 기울기와 절편을 추정한다.

## 9. MAE — 평균절대오차

MAE(Mean Absolute Error)는 실제값과 예측값의 차이를 절댓값으로 바꾸어 평균한 값이다.

### 공식

\[
MAE = \frac{1}{n}\sum_{i=1}^{n}|y_i-\hat{y}_i|
\]

### 실습 결과

```text
MAE = 2,493
```

모델의 예측값이 실제값과 평균적으로 약 2,493만큼 차이 났다는 의미다.

단위는 예측 대상인 가격 데이터와 같다.

### 특징

- 예측 오차의 평균적인 크기를 이해하기 쉽다.
- 오차가 작을수록 좋은 결과다.
- 오차의 방향보다 크기를 평가한다.

**핵심:** MAE는 모델의 예측이 실제값에서 평균적으로 얼마나 벗어났는지 나타낸다.

---

## 10. MSE — 평균제곱오차

MSE(Mean Squared Error)는 실제값과 예측값의 차이를 제곱한 후 평균한 값이다.

### 공식

\[
MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2
\]

### 실습 결과

```text
MSE = 16,240,971
```

### 특징

- 오차를 제곱하므로 큰 오차에 더 민감하다.
- 이상치가 포함되면 값이 크게 증가할 수 있다.
- 단위가 원래 예측 대상 단위의 제곱이 된다.

**핵심:** MSE는 큰 예측 오차에 더 큰 불이익을 주는 평가 지표다.

---

## 11. RMSE — 평균제곱근오차

RMSE(Root Mean Squared Error)는 MSE에 제곱근을 적용한 값이다.

### 공식

\[
RMSE = \sqrt{MSE}
\]

### 실습 결과

```text
RMSE = 4,030
```

### 특징

- 큰 예측 오차에 민감하다.
- 예측 대상과 단위가 같다.
- MAE와 함께 모델의 오차를 평가할 때 자주 사용한다.

### MAE와 RMSE 비교

| 지표 | 값 |
|---|---:|
| MAE | 2,493 |
| RMSE | 4,030 |

이번 실습에서는 RMSE가 MAE보다 크게 나타났다.

이는 상대적으로 큰 예측 오차가 존재한다는 점을 살펴볼 단서가 된다.

**핵심:** RMSE는 큰 오차의 영향을 더 크게 반영하므로 MAE와 함께 비교하면 유용하다.

## 12. R² — 결정계수

R²(R-squared, 결정계수)는 회귀 모델이 실제 데이터의 변동을 얼마나 설명하는지 나타내는 지표다.

### 실습 결과

```text
R_SCORE = 0.803
```

이번 모델의 결정계수는 약 0.803이었다.

이는 해당 데이터에 대해 모델이 목표값 변동의 약 80.3%를 설명한다는 의미다.

### R² 해석

| 값 | 일반적인 의미 |
|---|---|
| 1 | 완벽한 예측 |
| 1에 가까움 | 모델의 설명력이 높음 |
| 0 | 평균값만 예측하는 기준 모델과 같은 수준 |
| 음수 | 평균값을 예측하는 기준 모델보다 성능이 나쁨 |

R²가 높다고 해서 모든 개별 예측이 정확하다는 뜻은 아니며, 반드시 일반화 성능이 좋다는 의미도 아니다.

**핵심:** R²는 회귀 모델이 데이터의 변동을 얼마나 설명하는지 평가하는 지표다.

## 13. 특이매물 — 이상치 분석

이번 실습에서는 일반적인 패턴과 다른 특이매물을 확인했다.

### 실습 결과

```text
특이매물 [53 13  2 92 71]
정상매물 195
```

전체 200건 중 특이매물 5건을 구분하고, 나머지 195건을 일반 매물로 분석했다.

### 이상치가 모델에 미치는 영향

- 일반적인 데이터 패턴과 크게 다른 값은 회귀선에 영향을 줄 수 있다.
- 오차를 제곱하는 MSE와 RMSE는 큰 오차에 민감하다.
- 이상치를 포함하거나 제외함에 따라 평가 결과가 달라질 수 있다.

단, 이상치라고 해서 반드시 잘못된 데이터는 아니다. 실제로 존재하는 특이한 사례일 수도 있다.

**핵심:** 이상치를 제거하기 전에 해당 데이터가 왜 특이한지 확인하는 과정이 필요하다.

## 14. 이상치 제외 전후 모델 성능 비교

### 실습 결과

| 평가 지표 | 전체 200건 | 특이매물 제외 195건 |
|---|---:|---:|
| MAE | 2,492.50 | 2,075.10 |
| RMSE | 4,030.01 | 2,731.54 |
| R² | 0.8034 | 0.9024 |

### 분석 결과

**MAE**

2,492.50에서 2,075.10으로 감소했다.

일반 매물만 평가했을 때 평균 절대오차가 줄어들었다.

**RMSE**

4,030.01에서 2,731.54로 감소했다.

큰 예측 오차의 영향을 반영하는 RMSE가 상당히 감소했다.

**R²**

0.8034에서 0.9024로 증가했다.

특이매물을 제외한 195건에 대해서는 결정계수가 약 90.2%로 나타났다.

### 결과 해석 시 주의할 점

이번 결과는 **평가 대상에서 특이매물을 제외했을 때의 성능 변화**를 보여준다.

따라서 성능 지표가 좋아졌다고 해서 모델 자체가 더 정확하게 학습되었다고 단정할 수는 없다.

서로 다른 데이터 집합에서 평가한 값이므로, 실제 모델 개선 여부를 판단하려면 동일한 검증 데이터에서 비교해야 한다.

**핵심:** 이상치가 회귀 모델의 평가 지표에 큰 영향을 미칠 수 있으며, 평가 대상이 달라졌다는 점도 함께 고려해야 한다.

## 16. 실습에서 확인한 주요 사항

| 항목 | 학습한 내용 |
|---|---|
| 무작위 표본 | 표본에 따라 상관계수가 크게 달라질 수 있음 |
| `random_state` | 같은 조건에서 동일한 표본을 재현 |
| 상관계수 0.896 | 강한 양의 선형 관계 |
| 기울기 439.46 | 면적 1단위 증가 시 예측 가격의 변화량 |
| 절편 5,926.68 | 회귀직선의 시작 기준값 |
| MAE 2,493 | 평균적인 예측 오차 |
| RMSE 4,030 | 큰 오차를 더 민감하게 반영 |
| R² 0.803 | 모델의 설명력 약 80.3% |
| 특이매물 5건 | 전체 평가 지표에 영향을 미치는 데이터 |
| 특이매물 제외 | 일반 매물에서 오차 감소 및 R² 증가 |

### 추가 확인사항

- 상관계수와 R²는 서로 다른 개념이다.
- 단순 선형회귀에서 절편이 있는 모델을 같은 데이터로 평가하면 R²가 상관계수 제곱과 일치할 수 있다.
- `sample()`을 활용한 일부 표본 분석은 전체 데이터의 결과와 다를 수 있다.
- 선형회귀의 기울기와 절편은 학습 데이터에 따라 달라질 수 있다.
- MAE, MSE, RMSE는 낮을수록 좋지만 R²는 일반적으로 높을수록 좋다.
- 이상치 제거는 항상 성능 개선을 의미하지 않으므로 신중하게 판단해야 한다.

> Pandas를 활용해 주택 데이터의 통계적 특성과 상관관계를 분석하고, 선형회귀 모델을 학습해 주택 가격을 예측했다. 기울기와 절편의 의미를 이해하고 MAE, MSE, RMSE, R²로 예측 성능을 평가했으며, 특이매물 5건을 제외한 결과와 비교하여 이상치가 모델 평가에 미치는 영향을 확인했다.
