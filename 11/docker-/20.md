## 1. Python 리스트와 NumPy 배열의 차이

Python 리스트는 여러 데이터를 순서대로 저장할 수 있는 자료구조이다.

```python
amounts = [3200, 1500, 15000, 6500, 32000, 4800,
           10900, 1500, 2700, 3000, 18500, 7000]

print(amounts)
print("합계:", sum(amounts))
print(amounts * 2)
```

### 리스트의 특징

리스트에 `* 2`를 사용하면 각 숫자가 두 배가 되는 것이 아니라 리스트 전체가 두 번 반복된다.

```python
numbers = [1, 2, 3]

print(numbers * 2)
```

실행 결과:

```text
[1, 2, 3, 1, 2, 3]
```

반면 NumPy 배열에서는 각 원소에 계산을 적용할 수 있다.

```python
import numpy as np

arr = np.array([1, 2, 3])

print(arr * 2)
```

실행 결과:

```text
[2 4 6]
```

| 구분 | Python 리스트 | NumPy 배열 |
|---|---|---|
| 생성 | `[1, 2, 3]` | `np.array([1, 2, 3])` |
| `* 2` | 리스트 반복 | 각 원소에 2 곱하기 |
| 수치 계산 | 반복문 등을 활용 | 배열 단위 연산 가능 |
| 주요 용도 | 일반 데이터 저장 | 수치 계산 및 데이터 분석 |

**핵심:** NumPy 배열은 여러 숫자를 한 번에 계산할 수 있어 데이터 분석에 유용하다.

## 2. NumPy 배열 생성 및 집계 함수

`np.array()`는 Python 리스트를 NumPy 배열로 변환하는 함수이다.

```python
import numpy as np

arr = np.array(amounts)

print("합계:", arr.sum())
print("평균:", round(arr.mean()))
print("최소:", arr.min())
print("최대:", arr.max())
```

### 주요 메서드

| 메서드 | 역할 |
|---|---|
| `np.array()` | NumPy 배열 생성 |
| `arr.sum()` | 모든 값의 합계 |
| `arr.mean()` | 평균 |
| `arr.min()` | 최솟값 |
| `arr.max()` | 최댓값 |
| `round()` | 반올림 |

### 배열 정보 확인

```python
print("모양:", arr.shape)
print("데이터 타입:", arr.dtype)
```

- `shape`: 배열의 차원별 크기
- `dtype`: 배열에 저장된 데이터의 자료형

예를 들어 12개의 정수로 이루어진 1차원 배열이라면 `shape`는 `(12,)`이다.

## 3. NumPy 조건 필터링

NumPy에서는 배열에 비교 연산자를 적용하면 각 원소에 대한 참·거짓 결과를 얻을 수 있다.

```python
print(arr >= 10000)
```

10,000원 이상인 값은 `True`, 미만인 값은 `False`로 표시된다.

### 조건에 맞는 데이터 추출

```python
arr[arr >= 10000]
```

실행 결과:

```text
array([15000, 32000, 10900, 18500])
```

### 실행 원리

1. `arr >= 10000`으로 각 원소를 비교한다.
2. 조건을 만족하는 원소에는 `True`가 표시된다.
3. `arr[조건식]`으로 `True`에 해당하는 데이터만 추출한다.

**핵심:** NumPy 배열은 조건식을 이용해 원하는 값만 선택할 수 있다.

## 4. zip()과 for문을 활용한 데이터 집계

서로 관련된 리스트를 함께 순회할 때 `zip()`을 사용할 수 있다.

```python
food = 0

for c, a in zip(categories, amounts):
    if c == "식비":
        food = food + a

print(food)
```

### 코드 해석

| 코드 | 의미 |
|---|---|
| `zip(categories, amounts)` | 두 리스트의 같은 위치에 있는 값을 묶음 |
| `for c, a in ...` | 묶인 값을 각각 `c`, `a`에 저장 |
| `if c == "식비"` | 카테고리가 식비인지 확인 |
| `food = food + a` | 식비 금액을 누적 |

이 코드는 식비에 해당하는 금액만 더하여 총식비를 계산한다.

## 5. Pandas DataFrame 생성

Pandas의 `DataFrame`은 행과 열로 이루어진 표 형태의 자료구조이다.

```python
import pandas as pd

spend = pd.DataFrame({
    "day": [2, 3, 4, 5, 7, 9, 12, 14, 16, 19, 20, 25],
    "shop": shops,
    "category": categories,
    "amount": amounts
})
```

### DataFrame 구성

| 컬럼 | 의미 |
|---|---|
| `day` | 사용 날짜 |
| `shop` | 사용처 |
| `category` | 소비 분류 |
| `amount` | 사용 금액 |

딕셔너리의 키는 컬럼 이름이 되고, 값으로 지정한 리스트는 해당 컬럼의 데이터가 된다.

### 데이터 확인

```python
spend.head(5)
spend.info()
spend.shape
```

| 코드 | 기능 |
|---|---|
| `head(5)` | 앞에서 5행 조회 |
| `info()` | 컬럼, 자료형, 결측치 관련 정보 확인 |
| `shape` | 행과 열의 개수 확인 |

**핵심:** DataFrame을 사용하면 여러 종류의 데이터를 표 형태로 관리하고 분석할 수 있다.

## 6. DataFrame 컬럼 선택

Pandas에서는 대괄호를 이용해 필요한 컬럼을 선택할 수 있다.

### 컬럼 하나 선택

```python
spend["amount"]
```

`amount` 컬럼 하나를 가져오며, 일반적으로 Series 형태로 반환된다.

### 컬럼 여러 개 선택

```python
spend[["shop", "amount"]]
```

두 컬럼을 선택한 DataFrame이 반환된다.

| 문법 | 결과 |
|---|---|
| `spend["amount"]` | 하나의 컬럼 (Series) |
| `spend[["shop", "amount"]]` | 여러 컬럼 (DataFrame) |

**핵심:** 여러 컬럼을 조회하려면 컬럼 이름들을 리스트로 묶어 대괄호를 두 겹 사용한다.

## 7. Pandas 집계 함수

특정 컬럼의 합계, 평균 등을 계산할 수 있다.

```python
print("합계:", spend["amount"].sum())
print("평균:", round(spend["amount"].mean(), 2))
```

### 코드 해석

- `spend["amount"]`: 금액 컬럼 선택
- `.sum()`: 금액 합계 계산
- `.mean()`: 금액 평균 계산
- `round(..., 2)`: 소수점 둘째 자리까지 반올림

NumPy 배열에서 사용했던 집계 함수와 비슷한 방식으로 활용할 수 있다.

## 8. 조건식을 활용한 행 필터링

Pandas에서는 조건을 만족하는 행만 선택할 수 있다.

### 문화 카테고리 조회

```python
spend["category"] == "문화"
```

이 코드는 각 행의 카테고리가 문화인지 비교하여 `True` 또는 `False`를 반환한다.

```python
spend[spend["category"] == "문화"]
```

이렇게 DataFrame을 다시 대괄호로 감싸면 조건을 만족하는 행만 조회할 수 있다.

### 10,000원 이상 사용한 내역

```python
spend[spend["amount"] >= 10000]
```

금액이 10,000원 이상인 행만 추출한다.

### 여러 조건 사용

식비이면서 5,000원 이상 사용한 내역을 조회한다.

```python
spend[
    (spend["category"] == "식비") &
    (spend["amount"] >= 5000)
]
```

| 연산자 | 의미 |
|---|---|
| `==` | 값이 같음 |
| `>=` | 크거나 같음 |
| `&` | 두 조건 모두 만족 |
| `\|` | 둘 중 하나 이상의 조건 만족 |

Pandas에서 여러 조건을 결합할 때는 각각의 조건식을 괄호로 감싸야 한다.

**핵심:** `df[조건식]`은 조건의 결과가 `True`인 행만 반환한다.

## 9. sort_values() — 데이터 정렬

`sort_values()`는 특정 컬럼을 기준으로 데이터를 정렬하는 메서드이다.

### 금액이 높은 순서로 상위 3개 조회

```python
top3 = spend.sort_values("amount", ascending=False).head(3)

top3
```

### 실행 과정

1. `sort_values("amount")`로 금액 컬럼을 기준으로 정렬한다.
2. `ascending=False`로 내림차순을 지정한다.
3. `head(3)`으로 상위 3행만 가져온다.
4. `top3` 변수에 결과를 저장한다.

| 옵션 | 의미 |
|---|---|
| `ascending=True` | 오름차순 |
| `ascending=False` | 내림차순 |
| `head(3)` | 앞의 3행 조회 |

**핵심:** 정렬과 `head()`를 조합하면 상위 N개의 데이터를 쉽게 조회할 수 있다.

## 10. 새로운 컬럼 생성

기존 컬럼을 계산하여 새로운 컬럼을 만들 수 있다.

### 100원당 1포인트 계산

```python
spend["point"] = spend["amount"] // 100
```

`//`는 나눗셈의 몫을 구하는 연산자이다.

예를 들어 3,200원을 사용했다면:

```python
3200 // 100  # 32
```

32포인트가 계산된다.

### 나눗셈 연산자 비교

| 연산자 | 역할 | 예시 |
|---|---|---|
| `/` | 일반 나눗셈 | `3200 / 100` → `32.0` |
| `//` | 몫 계산 | `3200 // 100` → `32` |
| `%` | 나머지 계산 | `3200 % 100` → `0` |

**핵심:** DataFrame의 기존 컬럼을 이용하면 새로운 계산 컬럼을 추가할 수 있다.

## 11. loc[] — 특정 데이터 수정

`loc[]`는 행 레이블과 컬럼 이름을 지정해 데이터를 선택하거나 수정할 때 사용한다.

```python
spend.loc[2, "amount"] = 14000
```

### 코드 해석

| 코드 | 의미 |
|---|---|
| `spend` | DataFrame |
| `.loc[]` | 레이블 기준 데이터 접근 |
| `2` | 인덱스 레이블 2 |
| `"amount"` | 수정할 컬럼 |
| `= 14000` | 새로운 값 저장 |

금액을 변경한 다음에는 기존에 계산한 포인트도 다시 계산해야 한다.

```python
spend["point"] = spend["amount"] // 100
```

**핵심:** 원본 데이터를 수정하더라도 이미 계산된 다른 컬럼의 값은 자동으로 다시 계산되지 않을 수 있으므로 필요한 계산을 다시 실행해야 한다.

## 12. groupby() — 그룹별 데이터 집계

`groupby()`는 특정 컬럼을 기준으로 데이터를 그룹으로 묶는 메서드이다.

### 카테고리별 사용 금액 합계

```python
spend.groupby("category")["amount"].sum()
```

### 코드 실행 과정

1. `groupby("category")`: 카테고리가 같은 데이터끼리 묶는다.
2. `["amount"]`: 금액 컬럼을 선택한다.
3. `.sum()`: 각 그룹의 금액을 합산한다.

### 사용 금액이 높은 순서로 정렬

```python
spend.groupby("category")["amount"].sum().sort_values(ascending=False)
```

그룹별 금액 합계를 계산한 뒤 큰 순서로 정렬한다.

### SQL과 비교

```sql
SELECT
    category,
    SUM(amount)
FROM spend
GROUP BY category;
```

SQL의 `GROUP BY`와 Pandas의 `groupby()`는 데이터를 그룹별로 집계한다는 공통점이 있다.

**핵심:** `groupby()`와 집계 함수를 조합하면 카테고리별 합계나 평균 등을 계산할 수 있다.

## 13. value_counts() — 항목별 개수 계산

`value_counts()`는 특정 컬럼에서 각 값이 몇 번 등장했는지 계산한다.

```python
spend["category"].value_counts()
```

예를 들어 다음과 같은 결과를 얻을 수 있다.

```text
식비    5
문화    3
교통    2
쇼핑    2
```

### groupby()와 value_counts() 비교

| 메서드 | 역할 |
|---|---|
| `groupby("category")["amount"].sum()` | 카테고리별 금액 합계 |
| `spend["category"].value_counts()` | 카테고리별 데이터 개수 |

`groupby()`는 다양한 집계에 활용할 수 있고, `value_counts()`는 항목별 빈도 계산에 편리하다.

## 14. 실습 오류 및 수정 사항

오늘 작성한 코드에서 컬럼 이름과 실행 순서에 따른 오류를 확인했다.

| 오류 또는 주의사항 | 원인 | 해결 방법 |
|---|---|---|
| `KeyError: 'amount'` | 컬럼 이름을 `amonut`으로 잘못 생성 | `amount`로 통일 |
| `KeyError: 'amounts'` | Python 리스트 변수와 DataFrame 컬럼 이름 혼동 | `spend["amount"]` 사용 |
| `spend["amonut"]` | 컬럼 이름 오타 | `spend["amount"]` |
| 컬럼 생성 전 `spend` 사용 | DataFrame이 아직 정의되지 않음 | 생성 셀부터 실행 |
| 수정 전 포인트 값 유지 | 금액 수정 후 재계산하지 않음 | `point` 컬럼 다시 계산 |
| 셀 실행 결과가 예상과 다름 | Jupyter 셀 실행 순서 차이 | 커널 재시작 후 순서대로 실행 |

### 추가 확인사항

- Python의 `amounts`는 리스트 변수이고, `"amount"`는 DataFrame의 컬럼 이름이다.
- `spend["amount"]`는 컬럼을 선택하지만 `spend[조건식]`은 조건에 맞는 행을 선택한다.
- `sort_values()`는 기본적으로 원본 DataFrame을 직접 변경하지 않고 정렬된 결과를 반환한다.
- `loc[]`는 위치 번호가 아니라 인덱스 레이블을 기준으로 데이터를 선택한다.
- Jupyter Notebook에서는 셀을 실행한 순서에 따라 변수에 저장된 값이 달라질 수 있다.
