## 1. psycopg — PostgreSQL 데이터베이스 연결

Python에서 PostgreSQL 데이터베이스에 접근하기 위해 `psycopg` 라이브러리를 사용했다.

```python
import psycopg
from psycopg.rows import dict_row

DSN = "host=localhost port=5432 dbname=sportscenter user=postgres password=..."

with psycopg.connect(DSN, row_factory=dict_row) as conn:
    ...
```

| 코드 | 의미 |
|---|---|
| `psycopg` | PostgreSQL 연결 라이브러리 |
| `DSN` | 데이터베이스 연결 정보 |
| `psycopg.connect()` | 데이터베이스 연결 |
| `dict_row` | 조회 결과를 딕셔너리 형태로 반환 |
| `conn` | 데이터베이스 연결 객체 |
| `with` | 연결과 트랜잭션 관리 |

**핵심:** Python에서 SQL을 실행하려면 먼저 데이터베이스 연결 객체가 필요하다.

## 2. execute(), fetchone(), fetchall() — 데이터 조회

`execute()`는 SQL을 실행하고, `fetchone()`과 `fetchall()`은 조회된 결과를 가져오는 역할을 한다.

```python
row = conn.execute(
    "SELECT member_id FROM members WHERE name = %s",
    ("홍길동",)
).fetchone()
```

| 메서드 | 역할 |
|---|---|
| `execute()` | SQL 명령어 실행 |
| `fetchone()` | 조회 결과 한 행 가져오기 |
| `fetchall()` | 남아 있는 조회 결과 전체 가져오기 |

`dict_row`를 사용했다면 다음처럼 컬럼 이름으로 접근할 수 있다.

```python
row["member_id"]
```

**핵심:** `execute()`는 SQL 실행, `fetchone()`은 결과 한 행 조회, `row`는 가져온 결과를 저장하는 변수이다.

## 3. %s — SQL 매개변수 전달

Python에서 SQL에 값을 전달할 때 `%s`를 사용한다.

```python
name = "홍길동"

row = conn.execute(
    """
    SELECT member_id
    FROM members
    WHERE name = %s
    """,
    (name,)
).fetchone()
```

### 코드 해석

| 코드 | 의미 |
|---|---|
| `SELECT member_id` | 회원 번호 조회 |
| `FROM members` | 회원 테이블 사용 |
| `WHERE name = %s` | 전달받은 이름과 비교 |
| `(name,)` | Python 변수의 값을 튜플로 전달 |
| `.fetchone()` | 조회 결과 한 행 가져오기 |

여기서 `%s`는 변수 이름을 참조하는 것이 아니라 전달받은 값을 순서대로 사용한다.

### 여러 개의 %s 사용

```python
member_id = 10
course_id = 3

conn.execute(
    """
    SELECT *
    FROM enrollments
    WHERE member_id = %s
      AND course_id = %s
    """,
    (member_id, course_id)
)
```

첫 번째 `%s`에는 `10`, 두 번째 `%s`에는 `3`이 전달된다.

**핵심:** SQL에 전달하는 값의 순서와 `%s`의 순서가 일치해야 한다.

## 4. DISTINCT — 중복 데이터 제거

`DISTINCT`는 조회 결과에서 중복된 행을 제거할 때 사용한다.

```sql
SELECT DISTINCT
    c.course_id,
    s.sport_name,
    c.course_name
FROM courses c
JOIN sports s ON c.sport_id = s.sport_id;
```

### DISTINCT의 특징

`DISTINCT`는 첫 번째 컬럼에만 적용되는 것이 아니라 SELECT에 작성된 모든 컬럼의 조합을 비교한다.

| course_id | sport_name |
|---|---|
| 1 | 수영 |
| 2 | 수영 |

위 두 행은 `sport_name`이 같더라도 `course_id`가 다르므로 중복으로 처리되지 않는다.

```sql
SELECT DISTINCT sport_name
FROM sports;
```

이렇게 종목 이름만 조회하면 중복된 종목 이름을 제거할 수 있다.

**핵심:** `DISTINCT`는 선택한 컬럼들의 값이 모두 같은 행만 중복으로 판단한다.

## 5. 함수 정의와 함수 호출

Python에서 `def`를 이용해 함수를 정의하고, 함수 이름 뒤에 괄호를 붙여 호출한다.

```python
def find_member_id(conn, name):
    ...
```

### 함수 정의와 호출의 차이

```python
# 함수 자체를 변수에 저장
MEMBER_ID = find_member_id

# 함수를 실행하고 반환값 저장
MEMBER_ID = find_member_id(conn, name)
```

| 코드 | 의미 |
|---|---|
| `find_member_id` | 함수 자체 |
| `find_member_id()` | 함수 호출 |
| `find_member_id(conn, name)` | 인자를 전달하여 함수 실행 |
| `return` | 함수 실행 결과 반환 |

함수 이름에 괄호를 붙이지 않으면 함수 내부의 SQL이 실행되지 않는다.

## 6. 회원 이름으로 회원 ID 조회 함수 구현

오늘의 일일 과제 중 첫 번째 문제는 회원 이름을 입력받아 회원 ID를 조회하는 기능이었다.

### 회원 조회 함수

```python
def find_member_id(conn, name):
    row = conn.execute(
        """
        SELECT member_id
        FROM members
        WHERE name = %s
        """,
        (name,)
    ).fetchone()

    if row is not None:
        return row["member_id"]
    else:
        return None
```

### 실행 과정

1. `conn`과 `name`을 함수에 전달한다.
2. `SELECT`로 회원 번호를 조회한다.
3. `fetchone()`으로 조회 결과 한 행을 가져온다.
4. 회원이 존재하면 `row["member_id"]`를 반환한다.
5. 회원이 존재하지 않으면 `None`을 반환한다.

### return의 역할

```python
row = {"member_id": 10}

return row["member_id"]
```

`row`에 저장된 딕셔너리에서 `member_id`에 해당하는 값 `10`을 꺼내 반환한다.

| 반환 코드 | 결과 |
|---|---|
| `return name` | 회원 이름 반환 |
| `return row` | 조회 결과 전체 반환 |
| `return row["member_id"]` | 회원 번호 반환 |

**핵심:** 함수에서 어떤 값을 반환하는지에 따라 함수 밖에서 사용할 수 있는 데이터가 달라진다.

## 7. input() — 사용자 입력받기

`input()`은 사용자에게 값을 입력받는 함수이다.

```python
name = input("회원 이름을 입력하세요: ")
```

입력받은 이름을 회원 조회 함수에 전달할 수 있다.

```python
MEMBER_ID = find_member_id(conn, name)
```

### 회원 존재 여부 확인

```python
if MEMBER_ID is not None:
    print("회원 번호:", MEMBER_ID)
else:
    print("회원을 찾을 수 없습니다.")
```

- `is not None`: 조회된 회원이 있는지 확인
- `is None`: 조회된 회원이 없는지 확인

회원이 존재하지 않는 경우 수강 신청 함수가 실행되지 않도록 처리해야 한다.

## 8. 실습 오류 및 수정 사항

| 오류 | 원인 | 수정 |
|---|---|---|
| `def find member_id` | 함수 이름에 공백 사용 | `def find_member_id` |
| `return name` | 회원 ID 대신 이름 반환 | `return row["member_id"]` |
| `return row{"member_id"}` | 딕셔너리 접근 기호 오류 | `row["member_id"]` |
| `MEMBER_ID = find_member_id` | 함수 호출 누락 | `find_member_id(conn, name)` |
| 함수 정의 위치 | `main()` 실행 이후 함수 정의 | 실행문보다 위에 함수 정의 |
| 회원 미조회 시 신청 실행 | `None` 값이 신청 함수에 전달될 수 있음 | `if`로 회원 존재 여부 확인 |

### 함수 호출 시 주의사항

```python
find_member_id
```

함수 자체를 가리키는 표현이다.

```python
find_member_id(conn, name)
```

함수를 실행하고 결과를 반환받는 표현이다.

### 딕셔너리 접근 시 주의사항

```python
row = {"member_id": 10}
```

딕셔너리를 생성할 때는 `{}`를 사용하지만, 이미 생성된 딕셔너리에서 값을 꺼낼 때는 `[]`를 사용한다.
